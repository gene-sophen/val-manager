## 1. 设计参考与核心思路

| 参考 | 借鉴点 |
|---|---|
| 炉石传说 | 稀有度决定演出强度；高稀有度翻转揭示时的爆发瞬间 |
| 皇室战争 | 逐张翻开的节奏感 |
| UI-UX-MAX 动效准则 | ease-out 进场缓动；只动 transform/opacity；单视图聚焦一个主动效；避免过度位移 |

**核心原则（v2 修订）：反转（flip）是全流程唯一主语言。**
- 所有"出现"都用旋转表达：卡背入场是翻转旋入，揭示是 3D 翻转，不做平移、飞天、登台等位移类动作
- 低稀有度快速过场不拖节奏；高稀有度的仪式感靠**蓄力回旋 + 过冲翻转 + 分层爆闪**，不靠挪位置
- 屏幕级效果（压暗、震屏）为钻卡独占——这是画面反馈，不属于位移

## 2. 开包流程

1. **卡包待命**：卡包居中悬浮（呼吸浮动 + 红光晕），点击开启
2. **开包爆发**：卡包放大爆开
3. **逐张揭示**（v2.2）：卡背逐张居中出场（翻转旋入）→ 点击翻转揭示 → 短暂停留后翻转退出 → 自动流转下一张，顶部显示进度 `n / 10`。铜银停留短、金钻停留长
4. **结算牌阵**：10 张全部揭示后，以 5×2 牌阵总览（稀有度光晕驻留，一眼读出这包成色）
5. **全部翻开**：铜/银快速连翻（间隔约 170ms）；遇金/钻自动停下播完整演出，播完继续

## 3. 翻转动作分解（金/钻）

高稀有度翻转不是匀速转过去，而是三段式：

1. **充能**（原地）：稀有度光晕在卡缘渐亮，无任何移动
2. **回旋蓄力**：卡面先向反方向回掰（金 -14° / 钻 -18°，ease-in），像拉开弓弦
3. **过冲翻转**：以 `cubic-bezier(.2,.85,.3,1.12)` 翻转 180° 并轻微过冲回弹；在**刃面朝观众**的瞬间（约翻转进程 54%）引爆分层爆闪

## 4. 分层爆闪结构（金/钻）

v1 的单一径向闪光质量不足，v2 拆为五层叠加（均只动 transform/opacity）：

| 层 | 组件 | 表现 |
|---|---|---|
| 1 | 白炽核心 | 中心白点 → 稀有度色光球，screen 混合，0.5s 衰减 |
| 2 | 六边形冲击波环 ×2 | 呼应卡形的六边形描边环，双层错位 90ms 扩散消隐 |
| 3 | 光刃 ×4 | 0°/±60°/90° 四道细光带瞬时伸长收回 |
| 4 | 瞬时星芒 | 锐角辐条一次性炸开（0.42s），区别于驻留的慢速余晖 |
| 5 | 双层粒子 | 快火花（小而远）+ 重碎晶（大而近），末段统一带重力下坠 |

钻卡为金的全面加强版：核心更大（520 vs 380）、环扩散更远、粒子更多且彩色棱镜色。

## 5. 四稀有度特效规格

| | 铜 | 银 | 金 | 钻 |
|---|---|---|---|---|
| 总时长 | ~0.4s | ~1.0s | ~1.7s | ~2.8s |
| 翻转 | 直接翻转 0.38s | 直接翻转 0.5s | 回旋 -14° + 过冲翻转 0.72s | 回旋 -18° + 慢速过冲翻转 1.0s |
| 蓄力 | 无 | 无 | 原地金光充能 0.26s | 原地棱镜充能 0.3s + **全场压暗 74%** |
| 揭示瞬间 | 5 粒灰铜碎屑 | 小型白炽核心 + 8 粒银光 | 金系分层爆闪 + 金色余晖射线 1.7s | 钻系分层爆闪 + 棱镜余晖 2.7s + **震屏 0.3s** |
| 揭示后 | 弱铜晕驻留 | 扫光掠过 + 银晕驻留 | 金晕驻留 | 全息蒙版浮现 + 钻晕驻留 + 压暗解除 |
| 音效（待补） | 轻"咔" | 清脆金属声 | 低沉轰鸣 + 上扬音 | 专属长音效 + 和声 |

## 6. 设计要点

- **翻牌节奏即情绪曲线**：铜银不挡手，金让玩家"等一下"，钻让玩家"放下手看"
- **钻卡独占屏幕级反馈**：压暗 + 震屏，其他稀有度一律不做，保证稀缺感
- **驻留光晕**：翻开后保留稀有度光晕（铜最弱/钻最强），牌阵全貌一眼可读稀有度分布
- **可访问性**：正式版需支持 `prefers-reduced-motion`（震动/爆闪降级为简单翻转 + 淡入）
