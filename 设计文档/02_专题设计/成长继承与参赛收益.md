# 成长继承与参赛收益

更新：2026-10-05。当前正式前端已接入 `游戏/progression.js`，逐回合/休息/地图/比赛/阶段/年度去重、换人和跨年继承已实现。164 项回归与 60 个自动完整赛年通过。下方保留设计依据，涉及精细事件的额外配合、执行和关键表现加成仍待独立战斗引擎提供证据，当前数值模型不虚构这些收益。

实际实现的差异：首次地图教练积累统一 50，不凭空生成专长；旧单层地图分同时初始化 H/M 以保持现有显示，次年才重建 M。BO3/BO5 都只结算一次比赛层成长。战术评价目前比较当前地图分及英雄适配与中性基线的预期；临场评价按整图实际得分相对各分预期收缩，再按回合数聚合成系列赛目标，并非精细窗口后的行动评分。两维单场各最多 ±1，空间回合没有可靠概率样本时临场不更新。赛事熟识即时发放，年度只汇总并另结算一次声望。完整业务存档迁移仍未完成，不追溯重发旧历史收益。详见[本批验证](../../docs/validation/2026-10-05-growth.md)。

## 1. 五类数据分开保存

| 数据 | 生命周期 | 变化原则 |
|---|---|---|
| 选手卡定义 | 固定版本 | 枪法、协同、意识及既有机制不被成长覆盖 |
| 当届五人队 | 当前征战 | 羁绊、状态、熟练随比赛和换人调整 |
| 教练档案 | 跨征战 | 战术、临场、声望可升可降，历史成就另存 |
| 教练地图积累与选手熟识 | 跨征战 | 地图积累保留；熟识累加但羁绊收益递减 |
| 参赛事实与收益记录 | 永久历史 | 记录当时谁参加了什么比赛；换人不重写历史 |

2026-10-03 用户已确认队伍“羁绊/状态/熟练”与教练“战术/临场/声望”的名称及分工：状态合并心态与手感，临场替代经验。具体数值不由玩家加点，本文曲线仍待平衡。永久图鉴不恢复本轮上场资格，长期熟识也不把未抽到的选手加入阵容。

## 2. 按实际参赛名单结算

每次比赛开始冻结五人的卡实例 ID、卡版本 ID 和真实选手 ID。不能只保存队伍名，不能在年终用当前五人回填旧比赛。

```text
比赛记录：runId / eventId / matchId / 时间 / 五人名单 / 结果 / 来源 / rulesVersion
收益记录：rewardId / participantId / 来源比赛或赛事 / 收益种类 / 数值 / applied
荣誉记录：选手与卡版本 / 赛事 / 名次或冠军 / 参赛依据 / 获得时间
```

正式比赛与快速结算采用同一参赛、成长记账规则；展示方式不能改变资格。对同一赛事、选手与收益种类使用稳定唯一 ID，刷新、重放、重新打开年终页面都不重复加数值。

例：A 参加启点赛和大师赛①并夺冠，第一赛段前由 B 替换。A 得到自己参赛产生的熟识和大师赛①冠军；B 从入队后实际出场开始取得收益，不取得大师赛①荣誉。即便 A 的部分熟识在年终统一发放，也不能因 A 已离队而丢失。

当前规则只允许固定补强窗口换人，窗口在大段之间；不额外设计赛事中换人、替补或决赛临时挂名。

## 3. 熟识的累计与羁绊

**2026-10-03 用户已确认：熟识按真实选手共享，荣誉按实际参赛卡版本分别记录。**熟识以真实选手 ID 为主键，普通卡、钻卡与不同钻卡版本使用同一份教练关系；荣誉按卡版本 ID 保存实际参赛事实，不自动复制到其他版本。

例如普通版康康参加比赛积累熟识并夺冠，之后抽到钻卡康康，可使用已积累的熟识贡献基础羁绊，但钻卡不会因此获得普通版的冠军荣誉。每次参赛的熟识只计入真实选手一次，不因已解锁多个版本而多发。既定收益递减、离队收益保留、卡面三维固定及未抽到卡不可上场等规则不变。

每场实际参赛获得基础熟识资格，再按相应赛事结果、教练声望和年度结果进行加权。具体系数暂不定；年度结果应按参赛贡献分摊，不能把整年奖励全给最终五人，或让仅参加早期比赛的离队者取得后来赛事专属冠军收益。

建议比赛时保存声望快照，用于该场对应收益，避免年终声望变化回溯影响整个赛年；年度额外奖励使用年终快照。两种来源分开标记，结算页可解释。此取值方案替代此前简单“所有收益一律年终声望”的建议，等待数值设计一起评估。

已确认熟识持续累加、对基础羁绊的收益递减。可用以下饱和曲线作第一轮测试：

```text
关系贡献 = 关系贡献上限 × 底层熟识累计U / (U + 半饱和值)
```

累计为零则贡献为零；达到半饱和值时得到上限的一半；继续积累始终有增量但不会无限提高初始羁绊。第 9 节已给出半饱和值 40、可见值 F=100×U/(U+40) 的首轮参数，羁绊只取 0.15×F，不再对 F 重复做一次饱和变换。这些参数仍需按赛年长度及补强价值调试。

## 4. 羁绊的组成与换人

基础关系可分为教练熟识、真实同队关系和本届共同比赛磨合，但界面仍展示一个队伍羁绊。真实同队按指定数据快照认定，不能每次联网读取现实转会后改历史。

建议本届磨合按两名队员的共同出场关系保存，五人共有十对关系。换一人保留原四人的六对关系，新人相关四对重新计算；换两人保留原三人的三对关系。全换时不继承离队队员之间的本届磨合，但新五人的已有熟识和真实同队关系依然有效。

这不是要求界面显示十条进度条。界面只给“保留四人关系，新人需要适应”等简明解释。历史熟识不因换走清零；旧卡已无本轮上场资格，不能靠反复换入换出刷关系。

## 5. 状态、熟练与地图的时间尺度

| 属性 | 比赛内 | 比赛/阶段间 | 新征战 |
|---|---|---|---|
| 状态 | 随关键失误、连续失利、高光等合理波动 | 向正常水平恢复，恢复幅度待验证 | 回到新阵容初始状态 |
| 羁绊 | 共同成功、有效配合等小幅积累 | 共同参赛继续磨合，换人按受影响关系重算 | 本届磨合重置，熟识与真实同队提供基础关系 |
| 熟练 | 体系执行经验缓慢变化，不因每次改排序大幅扣分 | 结合共同执行与换人变化 | 新五人重新建立体系掌握 |
| 地图分 | 不因每次击杀重复结算整张地图胜负 | 地图结束更新；教练积累与阵容磨合分别记录 | 教练部分保留，新阵容部分重建 |

上表将已确认的继承方向转为建议时序，不代表具体速度已拍板。每分评估三维，但净变化可以为零；赛后只新增整场贡献，不能把之前每回合的增量再发一遍。

地图分退出活跃池仍保存教练积累，重入时恢复对应记录。换人影响阵容部分，不删除教练已掌握的地图；仅换一人也不将整队地图经验全部清零。

## 6. 教练三维的更新

战术和临场是当前能力档案，声望是外部认可度，均可跨局升降。建议战术与临场缓慢变化，声望更多响应赛事成绩和超出预期的表现。

不能把“按了暂停”“改过一次排序”直接当作正收益，否则玩家会机械操作刷成长。应结合队伍条件、对手水平及比赛表现更新，单场只能提供有限证据。具体三维驱动与权重留在数值专题，不增加第四项永久执教等级。

阶段表现修正属于当届评估缓存，阶段结束清除；不写入教练三维后又单独带入下一阶段一次。

## 7. 失败、退出与存档

正常未晋级仍完成阶段/年度结算，实际出场者照常获对应收益。主动放弃采用首轮设计默认：保留已解锁图鉴、已完成比赛的基础熟识和已完成赛事荣誉；当前未结束的赛事只保留已经实际打完的比赛收益，不预发最终名次额外收益，不发未完成赛年的年度额外声望评价。正常退出页面或关闭应用不是放弃，保存检查点后可继续。

旧存档没有新三维与参赛归属字段时，保留原始历史，不凭当前阵容伪造过去出场。迁移版本与新增规则分开标记；旧四场测试荣誉不能自动换成正式大师赛冠军。

收益以比赛/赛事来源唯一编号提交。应用中断后先读已提交记录再补未提交项，不能整页重新发奖；若版本缺字段，保留旧数据并显示所属旧版本，不用零值覆盖已有记录。

## 8. 验收例子

- A 大师赛夺冠后离队，年终仍可看到该荣誉与参赛收益；B 不追领入队前奖励。
- 未选中的初始包卡片在图鉴里，无参赛就没有熟识及冠军荣誉。
- 快速比赛出场与正式比赛同样产生记录；重复载入同一结果不重复发放。
- 换一人保留四名队员关系；地图教练积累保留，当前阵容部分更新。
- 熟识增加始终不使关系贡献下降，但后续边际收益下降。
- 未晋级大师赛也领到固定补强；没进冠军赛也正常总结当年实际成绩。

后续需要把这些例子转为规则测试；本轮只完成设计与数学边界检查，不宣称存档或引擎已实现。

## 9. 统一的 0–100 数值规格

用户已要求可视化数值尽量采用 0–100。下列为可实现的首轮参数草案：用户确认的是尺度及玩法关系，具体常数由设计提供，仍需引擎与试玩验证。

### 显示与保存

- 选手三维、队伍三维、教练三维、地图分及熟识显示值均在 0–100。
- 内部属性保留小数，面板默认整数，变化详情最多一位小数；不得先四舍五入再保存。很小变化合并到单图/赛后说明。
- 比分、胜场、暂停次数和历史累计场数使用实际计数，不强行改为百分制。
- 熟识的底层累计记录可超过 100，转换后的可见熟识始终不超过 100；隐藏战力不新增可见进度条。
- 所有模型中 clamp(x,0,100) 是属性边界；“属性 100”不等于成功率 100%，具体概率仍由对抗条件决定。

### 初始值和时间尺度

| 属性 | 首次开始 | 主要更新 | 跨征战 |
|---|---|---|---|
| 枪法 / 协同 / 意识 | 既有卡值 | 不成长 | 卡定义固定 |
| 羁绊 G | 下述三项关系公式 | 共同参赛与换人 | 熟识和真实同队提供新基础，本届关系重建 |
| 状态 S | 50 | 每回合较快变化、间歇恢复 | 重置 50 |
| 熟练 L | 40 + 0.2×教练战术 | 逐回合缓慢变化、赛后积累 | 新队重新按教练计算 |
| 教练战术 T / 临场 C / 声望 P | 各 50 | 战术与临场每场有限更新；声望阶段与年终更新 | 当前值保留，可升可降 |
| 教练地图积累 H | 首次建档各图 45–55，固定种子生成 | 单图结果相对预期修正 | 保留，不因退出池清零 |
| 阵容地图磨合 M | 50 | 实际打这张地图才变化，换人回归部分基础 | 新阵容重置 50 |
| 可见熟识 F | 0 | 出场收益换算 | 累计保留 |

首次地图差异是教练初始特色的设计默认值，不改变官方地图几何或选手基础值。新征战不重掷教练地图积累。

### 羁绊：关系有价值，换人有可解释的代价

```text
F均 = 当前五人的可见熟识平均值
同队比例 R = 十对选手中真实同队的对数 / 10
当届磨合 B = 当前十对选手关系值的平均值（每对 0–100）
G = clamp(20 + 0.15×F均 + 20×R + 0.45×B, 0, 100)
```

由此新组的陌生混合队羁绊为 20，真实五人同队初始为 40；熟识最多贡献 15 点，当届磨合最多贡献 45 点。同队加成不再另乘一遍全队战力。所有人都来自不同队伍仍可通过共同比赛建立关系。

每个实际共同参与回合，每对关系 +0.03；若有该两人有效配合的事件证据，再 +0.07，每对每回合最多 +0.10。每完成一个 BO3，每对再获得 +0.3 的共同参赛积累，不按赢输重复发回合收益。快速比赛执行相同记账，不能缺乏事件却编造额外配合加分。

换一人只重建该新人与四人的关系，其余六对保留；换两人保留原三人的三对。新配对本届值为零，教练熟识和真实同队加成另外按公式计算。该配对后来以新卡再次入队时，只复用双方真实存在的本届共同经历，不凭空加一次“招募收益”。

### 状态：短期波动与自然恢复

```text
每回合后 S' = clamp(50 + 0.90×(S−50) + 2×胜负方向 + 关键表现, 0, 100)
胜负方向：胜 +1，负 −1
关键表现：由实际高光/重大失误汇总，限制在 −1 到 +1
中场恢复：50 + 0.75×(S−50)
地图结束恢复：50 + 0.50×(S−50)
BO3 结束恢复：50 + 0.25×(S−50)
```

正常连续获胜趋近 70、连续失利趋近 30；持续关键事件的极端情况趋近 80 或 20，避免一次落后迅速归零。不同休息节点只在实际发生时各处理一次。

暂停时若 S<50，恢复量为 `(50−S)×(0.10+0.002×教练临场)`；S≥50 不白送状态。双方都可得到自己教练对应的恢复，只消耗发起方暂停额度。不会因为对方连续暂停而无限叠加固定正数。

### 熟练：学习体系，不惩罚正常调战术

每个完成的回合获得 `0.04×(1−L/100)`；有体系执行成功证据额外 `0.06×(1−L/100)`，有明确执行失误时额外扣 0.04；每回合总变化限制在 −0.04 到 +0.10。BO3 完成后再加 `0.3×(1−L/100)`，同样不要求胜利。

仅重排战术不直接扣熟练。换人后 `L'=初始熟练 + 留队人数/5×(L−初始熟练)`，夹在 0–100；全换回到当前教练提供的初始值。不是十套战术各建一条要训练的经验槽。

### 地图分：教练积累和阵容部分合成一个显示值

```text
单图后 H' = clamp(H + 2×(实际胜负−赛前预期胜率), 0, 100)
单图后 M' = clamp(M + 学习速率×(1−M/100), 0, 100)
学习速率：获胜 1.5，失利 0.8
显示地图分 D = 0.6×H + 0.4×M
换人后的 M' = 50 + (留队人数/5)×(M−50)
```

胜利为 1、失败为 0。预期胜率在图开始前保存，不能在赢后改预测。失利仍积累地图经历，但教练地图评价可下降；熟悉不代表必胜。换图只换活跃集合，H 的历史记录保留。新征战 M=50，继承 H。

### 熟识：累积不丢，面板不溢出

底层累计记为 U，初值零：`F=100×U/(U+40)`。U=40 时 F=50，U=120 时 F=75。面板采用该值；上文关系公式只使用 F，不再额外叠加 U。

每个实际出场地图获得 `ΔU=(1+0.25×是否获胜)×(0.75+0.005×赛前声望)`；整个 BO3 不再重复发一份同名基础熟识。声望快照在该图开赛时冻结。地图数更多代表更多共同经历，但不奖励重放或重复载入。

年度成果额外收益依据该选手实际参与的赛事逐项汇总：启点赛、常规赛、季后赛基础权重 1，大师赛 2，冠军赛 3；成绩档系数首轮取冠军 2、亚军 1.5、其余晋级淘汰阶段 1、其余完成参赛 0.5。`赛事额外U=权重×成绩档系数×该选手出场地图数/本队该赛事地图数`。五名全程队员各自取得完整对应份额，分母不是全队五人出场量之和。

赛事额外 U 在该赛事完结且名次确定后记录为应得，可即时结算；年终只汇总，不再发同一项。离队者仍取得自己参与赛事的对应份额；未参加冠军赛的选手不会因本队后来夺冠获得冠军赛收益。这样赛年成绩通过实际参加的赛事成果体现，不虚构离队后的参赛。

### 教练：慢速变化，声望对成绩更敏感

T、C 每场采用有证据的 0–100 评价目标做缓慢更新：`X'=clamp(X+clamp(0.05×(评价目标−X),−1,+1),0,100)`。没有可靠评价证据时保持原值，不按暂停次数评分。

战术评价目标首轮定义为 `clamp(50+100×(布置后预期胜率−标准布置预期胜率),0,100)`，比较同阵容同对手的 BP、英雄适配与计划效果；临场评价使用合法窗口后的实际表现相对该窗口预期表现，按样本量收缩后映射到 0–100。临场评价不要求一定调整，不调整也可合理；短样本及随机高光不能被宣称为精准教练能力测量。

声望阶段更新 `P'=clamp(P+clamp(0.10×(赛事成绩评价−P),−4,+4),0,100)`；成绩评价先按赛事名次分位得到 0–100，再在测试中审查不同赛事规模的偏差。年终以赛事权重加权的年度评价再进行一次最大 ±4 的年度评价更新，作为单独记录；不是重复颁发各赛事的声望奖励。

临场评价的具体事件聚合及预期模型仍依赖战斗引擎标定，是剩余的数值验证项；不以文档公式存在就标成引擎完成。

### 战斗修正的上限

首轮将状态的通用发挥修正限制在 `(S−50)×0.001`，范围 ±5%。羁绊只影响配合，熟练只影响计划完成，地图分只影响该图适应，教练只影响布置/判断，不各自给所有对枪加一层乘法。

同一个判定中，来自队伍、地图、教练和临时阶段修正的累计基础能力偏移先限制在 ±12%，战术机会修正必须共享对应判定预算，不能绕过上限。选手品质差距、武器与地形是不同来源，保留各自模型；任何 100 分属性不保证命中或获胜。±12% 是首轮防止叠加失控的实验上限，仍需真实对抗验证。
