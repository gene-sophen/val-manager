# 地图候选库与数据覆盖审阅表

更新：2026-10-03。状态：**2026-10-03 用户审阅通过，首版采用本稿九图并保留 Fracture；地图制作与引擎改造尚未开始。**

## 建议采用的首版范围

首版建议制作九张：**Ascent、Sunset、Split、Haven、Lotus、Breeze、Summit、Abyss、Fracture**。九图是满足“七张活跃图、每次换出两张并换入两张”的最小制作规模；所选九图都在本次读取的近期战绩中出现过。

其中前七张数据较广，Abyss 较少，Fracture 极少。**推荐九图不意味着九图数据同样可靠，也不表示这是现实某届赛事的官方七图池。**这是在已确认随机轮换规则下的游戏内容建议。优先保留地图之间的战术差异，不为凑数量复制 Ascent 的路线。

初始从这九张随机抽七张；第一赛段、第二赛段开始前，各从当前七张随机移出两张，再加入轮换前池外的两张。被移出的地图当次不能立即回填；下次可重新进入。九图版本的换入对象只有两张，随机性来自开局抽取及换出对象；以后扩到十张以上，换入对象也会有选择空间。

| Lotus | 47 | 12 | 199 | 纳入；支持三个包点 |

## 地图制作清单

以下是工程建议，不是对现有实现的完成声明。地图主题依据官方地图介绍；具体节点、距离、碰撞与技能影响要在实施时对照实际地图校对。

| 地图 | 需要体现的差异 | 本游戏中的实现重点 |
|---|---|---|
| Ascent | 中路与两包点、门 | 复用当前节点；核对转点用时、门状态、视野、攻防五类行为 |
| Sunset | 多路线争夺 | 区分控图、正面推进与转点，不能复用同一张图的路径编号 |
| Split | 高低层与绳索 | 用层级节点和连接表达，不增加玩家攀爬操作 |
| Haven | 三包点防守 | 支持第三包点、薄弱区判断、回防与假打转点 |
| Lotus | 三包点与门 | 门状态影响可达路线与声音，回合结束正确重置 |
| Breeze | 宽阔区域与远距离 | 射线、遮蔽、交战距离和增援时间一致 |
| Summit | 改变当回合布局的墙体 | 动态改变可通行与可见关系，并同步回放状态 |
| Abyss | 坠落边缘 | 明确不可通行边界与风险连接，禁止 AI 无原因反复坠落 |
| Fracture | 多侧进攻与夹击 | 支持多入口集合、夹击时序，防守转点有真实时间成本 |

选手自主处理门、绳索、特殊通路与队内配合。教练仍只做 BP、英雄选择和合法窗口内的战术排序，不新增地图机关微操。

现有地图文件包括 [ascent.json](../../引擎/maps/ascent.json)、[ascent_like.json](../../引擎/maps/ascent_like.json) 和 [ascent_site_test.json](../../引擎/maps/ascent_site_test.json)。后两者是同类结构/局部实验，不能计作另两张独立正式地图；当前也没有证明 Ascent 已通过新版规则验收。

## 胜率如何进入游戏

1. 保留原始胜负与样本量，缺失为缺失，不写成零胜率。阵容不一致的近三月混合数据只作弱参考。
2. 正式制作按明确赛事集合、比赛日期和出场名单筛选。少量全胜/全负向中性先验收缩；不把 1 胜 0 负变成 100 分。
3. 只提取队伍相对于自身平均水平的地图倾向；整体强弱已由选手卡等构成，不把 Ranking 与所有地图胜率再全额叠加。
4. 无可信样本的地图先用中性 50 作为地图初始化建议，并带缺数据标记；这不表示固定 50% 胜率。实际地图适配、英雄、战术与发挥仍影响结果。
5. 玩家选主队只继承赛事席位和种子依据，不继承该俱乐部的真实地图强项。玩家地图分沿用已确定的教练继承与阵容部分拆分。

参数收缩幅度与最终映射留给引擎对照实验，不要求用户先拍定小数。主规则见[赛程专题](阶段实力评估与赛程结算.md)及[成长与继承](成长继承与参赛收益.md)。

## 开工后的顺序与通过条件

先用 Ascent 走通新版系列赛、十套战术、暂停、状态变化和同源回放；再依次补齐一般双包点、三包点及特殊结构。Summit、Abyss、Fracture 的特殊规则单列检查，不能跳过后就把地图标为可用。

每张地图都须通过：攻守出生点可达、所有包点可安装/拆除、五类战术有合法路线、转点耗时一致、门墙变动不产生穿墙射击、回合重置正确、快速/正式同种子结果一致、2D 与日志位置和事件一致。满足这些条件后才加入有效地图清单；九张全部通过才能交付完整随机七图加两次轮换的征战版本。

地图轮换另检查：始终七张、无重复、每次恰好换出/换入两张、只在两次大段边界触发、存档恢复不二次抽图。初始全随机意味着任一候选图都有可能成为开局图，不能把尚未完成的地图藏在所谓“以后才轮换”的位置。
