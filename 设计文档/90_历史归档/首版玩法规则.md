## 已确认方向

- 每次征程随机开包取得上场选手；从本次获得的人选中选五人并执教。
- 征程内随机成长、阶段成长和有限补强；玩家可以在比赛中布置并调整战术。
- 征程结束保留图鉴、荣誉、历史；下次重新开包，重置可上场库存、成长与本次资源。
- 每队最多一张钻卡，同一选手的不同卡版本不能同时上场。

## 测试切片的可执行规则

| 操作/边界 | 条件与消耗 | 生效与后果 |
|---|---|---|
| 新征程 | 自动获得一包初始包，十张卡；不继承上轮库存 | 确定结果并保存后播放开包演出，首次确认不重复抽取 |
| 组队 | 从本次库存选五张不同选手卡；最多一钻；选特工、IGL、职责 | 赛前锁定五人/特工；阵容外的历史图鉴不能上场 |
| 极端缺额 | 若没有五名不同选手，可领取至多一包额外初始包；仍不足则显示无法开赛的明确错误 | 不暗改抽卡概率，不无限触发补给；实际兜底方案以分布验证后调整 |
| 重复卡 | 可以记录多个持有实例，同一选手仅一版可上场 | 重复卡不升级属性，也不在首版换成可无限续抽的货币 |
| 备战 | 每场正式比赛前一次机会，在训练、侦察、恢复中择一 | 使用时记录并按选项规定的持续范围生效；已用机会不得重复使用 |
| 正式对阵 | 四场固定对手的 BO1 验证切片；每图先到 13 胜，12 回合后换边 | 输球照实记录并继续剩余赛程；此切片不宣称复刻真实职业赛制 |
| 战术调整 | 回合间和中场可调整基础战术与 IGL | 玩家确认的计划优先；自动建议须明确接受或进入委托模式才生效 |
| 暂停 | 每个系列赛两次；中场窗口独立于两次常规暂停 | 仅在允许窗口消耗并施加状态干预，终局后不能再用 |
| 普通成长 | 第 1、2、3 场正式对阵结束，各生成并保存一次三选一；胜负都可选择 | 选一次后锁定；第 4 场后直接征程结算，不发立刻失效的成长 |
| 阶段节点 | 第 2 场后同时展示普通成长与一次大成长，并提供至多一包补强 | 同一个节点只结算一次；重新注册仅在阶段窗口；不因反复查看页面再发奖励 |
| 征程结束 | 第 4 场完成或测试征程按明示条件终止 | 先保存成绩/阵容/成长轨迹，再重置本次构筑；历史与图鉴保留 |

**术语：** 回合是一次攻防对抗；单图先到目标回合胜数；系列赛可以包含多图，切片只用 BO1；赛段是一组预定系列赛。正式联赛赛制与跨赛段规则另行验证。

## 本地比赛核的当前边界

- 当前引擎采用一秒逻辑 tick。旧版会在第 24 回合后平局时打一局决胜加时；正式赛制加时规则属于 L01/L03，切片如实标记这个简化方式。
- 爆能器已下时，进攻方全灭仍需真实抵达、开始、完成拆包。倒计时在逻辑步开始归零时先引爆；尚未归零才可继续该步动作。防守方全灭按当前本地核规则由进攻方获胜。
- 基础卡牌、征程成长、跨场状态、单场心态、回合效果分层。成长按条件判断和上限处理，固定卡面数据只读。相同效果同类叠加细则由 G06/G07 填入配置并验证，首版不默认无限乘算。
- 测试期成长叠加顺序：先读取卡牌基础值，再汇总本次征程内同一行为指标的训练效果，按该指标的配置上限截断，然后交给单场/回合状态处理。同名成果升级须有单项上限；互斥成果在候选生成与选择时均校验。具体指标与数值上限属于 G06/G07 的内容配置，未落地前不得显示为已生效。
- 比赛中关闭页面，从最近已保存的回合间检查点恢复；已确定的该回合输入与结果须保存，不能靠刷新重抽战果。局内每 tick 存档不是首版承诺。
