## 1. 重新确定玩家的工作

核心体验：我用随机获得的选手组建战队，为他们制定比赛计划，观看这支队伍自主比赛，在关键时刻进行调整，最终得到属于这套阵容的联赛成绩。

玩家负责谁上场、球队采用什么比赛思路、何时需要改变思路。选手负责枪法、走位、技能执行、补枪和残局；IGL 负责回合内信息判断与具体指挥。选手的能力、擅长位置和英雄池构成选人的依据，不要求玩家日常加点、维护熟练度或逐人修正操作。

必须满足一个基础条件：玩家确定五人阵容和比赛计划后，可以完整看完比赛，不再操作也能正常比赛与结算。自主队伍必须有完整战术执行能力，不能把少操作设计成故意变笨。

## 2. 当前复杂度来自哪里

| 当前操作 | 负担 | 建议 |
|---|---|---|
| 每回合点击继续 | 没有改变决定，也必须操作二十余次 | 自动衔接回合，连续观赛 |
| 修改七个战术权重 | 玩家在调参数，难以预测场面变化 | 改为少量有明确行为与代价的比赛计划 |
| 指定携包、单摸、假打、弱侧锚点 | 把执行层分工交给玩家重复配置 | 由 IGL 按选手特点和当前计划分配 |
| 五人的特工、IGL 全部逐项确认 | 首次建队出现过多表单 | 默认自动推荐合法阵容；特工配置是可选的教练干预 |
| 每场训练／侦察／恢复三选一 | 每场又多一轮优化作业，部分选项缺乏直观作用 | 自动完成基础备战，公开对手摘要；首版移除强制三选一 |
| 每场后选择成长 | 内容密集，容易变成堆增益 | 四场切片只在中段提供一次实质性的体系发展选择 |
| 单独领取、开包、成长、确认、推进 | 同一个阶段被拆成多次打断 | 合并阶段补强页面，减少无决策确认 |
| 全量战报和回合选择 | 玩家需要自行寻找看点 | 默认一段比赛总结与一至三个关键片段，详细数据按需查看 |

仅把旧表单折叠为“高级设置”不能解决问题。默认游戏本身应减少玩家职责，避免进阶玩家仍靠机械点击获取额外收益。

## 3. 保留的三层决定

### 建队：低频、影响整个征程

随机开包后选五人。支持一键推荐、手动换人，首轮默认保留推荐阵容。展示每名选手的擅长领域，以及这支队伍两项明显特点或缺口；不要逼玩家逐项核对三维数值。

特工阵容随地图和五人名单自动生成，优先英雄池与基本功能覆盖。玩家可以主动打开阵容页调整特工搭配；携包和具体执行职责仍交给队伍。IGL 由合适选手自动担任，作为阵容信息可见，不再出现在每回合操作区。

选手身份需要在比赛中被感受到：谁敢拿首杀、谁擅长补枪、谁稳定处理残局。这些特点由模拟表现形成，不能只靠卡牌稀有度和赛后文案。

### 赛前计划：每场一次，可直接沿用

用一个综合比赛计划取代攻防权重编辑。初版只做三种可读、可辨认的计划：

| 计划示例 | 进攻表现 | 防守表现 | 明确代价 |
|---|---|---|---|
| 主动争夺 | 集中资源拿关键区域，较早创造交战 | 有组织地前压争夺空间，允许回撤 | 暴露和早期减员风险较高 |
| 信息运营 | 探查与控图，确认信息后再集结 | 保留侦察和机动人员，根据有效信息轮转 | 容易被拖时间或压缩空间 |
| 稳健配合 | 减少孤立试探，优先多人配合进点 | 降低单人前压，重视交叉掩护与回防 | 可能放弃前期地图控制 |

这些是建议内容，并不声称当前引擎已经完整支持。每套计划必须先有实际的行为和失败分支，再上架为选项，不能用固定胜率加成替代。

计划延续到玩家修改为止；回合内具体打哪边、何时转点、谁使用技能，由 IGL 依据本队信息在计划范围内决定。自主调整不得静默改写玩家选择的大方向。

### 临场：少量、自愿、有依据

比赛默认连续播放。玩家可以完全不干预，也可以主动请求战术暂停，在下一个允许的回合间窗口调整。首版建议每张地图允许两次主动战术暂停，中场展示可主动打开的调整入口；不打开就沿用计划自动继续，不要求点击跳过。这是待试玩的游戏规则，不冒充职业比赛规则。

窗口展示一个有证据的问题，并提供“坚持原计划”及最多两个相关调整。例如多次进点前被消耗后，允许改为更早集结提速，或减少前期试探。调整应持续到后续修改，不需要每回合续点，也不能自动使下一回合获胜。

不因连败、下包或残局频繁弹出必须选择的窗口。助教提示以非阻断方式出现，不自动消费暂停。玩家点击“暂停观看”、拖动回放或切换播放速度，只改变观看，不计入战术操作。

首轮优先把临场调整限制为更换综合计划；待三套计划的行为差异可靠后，再考虑增加少量针对性修正。不要一开始组合节奏、方向、买枪、情绪、站位等多个控制轴。

## 4. 抽卡与肉鸽如何保留

抽卡保留每轮随机起点、有限额度和合法建队保障。选手基础实力保持为卡牌特征，玩家通过取舍阵容应对随机性。不能靠增加永久战力逐渐消除随机建队的意义。

肉鸽主要承担“这一轮球队怎样形成自己的特色”。四场测试切片建议只保留一个中段发展节点：在三种球队发展机会中选择一项，允许维持现有体系。成长描述围绕球队行为，例如更熟练的多人突破、更完整的回防协作；不增加逐人经验、属性加点和装备管理。

已有小成长效果可合并、改为阶段选项的内部组成，不必继续逐个向玩家发放。未来增加长赛季时，发展节点按赛段安排，不按每场机械发奖励。

阶段补强仍可提供一次随机补给，但新卡可以先进入候补席；玩家只在愿意换人时操作。不能因为领到补给而强迫重新确认整个阵容。成长机会和补强安排在同一阶段页面，避免连续弹窗。

## 5. 四场测试版的新流程

1. 开包 → 选五人（推荐阵容可直接采用）→ 选球队初始计划。
2. 查看下一场对手简报 → 沿用或更换计划 → 开始比赛。
3. 自动连续观赛 → 可切速度／看关键回合 → 玩家自行决定是否请求战术暂停。
4. 比赛结束 → 查看比分、关键表现和一个可回看的问题 → 继续赛程。
5. 第二场后进入唯一的阶段发展页 → 选择体系发展 → 可选补强换人。
6. 完成四场 → 查看排名、阵容表现与征程记录 → 新一轮随机起点。

默认的选手执行、买枪、基础备战、状态变化与战术分工全程自动处理。既有库存、图鉴、固定赛历与真实赛果保留。

## 6. 用什么检验深度与操作量

以下是下一轮试玩目标，不是已经验证的最佳数值：

- 开局建队可花较长时间；阵容确定后，一场比赛前只需一次“开始比赛”，不要求重新填表。
- 单图主动战术选择通常为赛前一次、中场可选一次、主动暂停最多两次，即约一至四次；观看控制不计入战术选择。
- 一套阵容和计划可以连续打完整个赛段，阶段发展集中为一次选择。
- 玩家能说出“我为何选这五个人”“我希望他们怎么打”“刚才的调整改变了什么”。不要求能解释内部权重和增益公式。
- 强阵容必须可以在合理默认计划下正常发挥。使用暂停不应成为每场必做的免费增益领取；不操作不能受到额外隐性惩罚。
- 同一对手、相近阵容下，计划改变应先体现为可观察的进点、控图、交战和回防差异，再检验比赛结果分布。
- 试玩同时记录强制停顿次数、玩家实际调整次数、第一次想跳过操作的位置，以及其对关键决定效果的理解。

参与感由阵容归属、清楚的意图、可辨认的选手表现及比赛悬念支撑，不依赖频繁点击。深度来自选人、计划、对手之间的关系，以及坚持或改变判断的时机。

## 7. 实施顺序与引擎要求

第一步先改交互节奏：自动推进回合，取消每回合确认；隐藏权重编辑和逐回合 IGL 选择；保存并沿用阵容与计划；取消强制备战选择；把赛后成长移至一个阶段节点。先用这版验证减负效果。

第二步补全自主球队：生成合法、适配的特工与职责配置；落实三种综合计划的行为；明确 IGL 的自主范围。推荐系统必须在正常规则内行动，不额外获得隐藏信息或能力加成。

第三步接入关键调整：将请求暂停排入下一个合法窗口，展示基于已发生事件的简报与少量选项。所有尚未发生的回合都应使用新计划继续模拟；不能事先算完整场赛果，再播放一段看似响应玩家的动画。

第四步优化观赛反馈：默认结果概览、球员表现、关键回合跳转；保留详细回放入口。播放暂停和倍速不得改变引擎随机序列与胜负。不能把模拟耗时误作球员反应时间。

第五步完成针对性试玩：比较新旧流程的停顿和实际选择，验证自主队伍能打完整比赛、暂停有用但非必用、选手特点可以被看出来。之后再扩大成长库、联赛长度和高级战术内容。

已有二维几何、视野、伤害、复盘、存档等基础仍然必要。此次调整提高了对选手与 IGL 自主决策质量的要求；减少玩家操作，并不意味着降低模拟可信度。
