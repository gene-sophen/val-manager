# 正式前端共享资源

这里只保存正式页面和Service Worker实际使用的资源。来源目录名称用于追溯；其余演示页面和构建脚本已移至 `归档/UI原型/`。

- `art-direction-01/players.js`：只读选手快照。
- `art-direction-03/`：卡牌渲染、卡包/收藏快照、卡牌样式及所需字体。
- `layout-rebuild-01/`：主界面/选手基础布局样式和字体。
- `navigation-rebuild-01/`：导航、子页与资料样式和字体。
- `compatibility.json`：14个历史资源URL到当前文件的映射，仅由静态构建生成旧URL兼容副本。

正式页面使用此目录中的新路径。兼容副本只出现在发布包，源码中不保留两套相同组件；历史字体许可证随字体保存。
