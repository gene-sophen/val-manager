## 体验流程

选择十二个 CN 主队之一 → 逐张揭晓三个十张包 → 三包全览选一个 → 从该包选五位不同选手 → 开始征战。不跨包、不设替补、最多一钻。未揭晓的卡不提前解锁，刷新不重抽。保留纸包开启、逐张完整卡面和钻卡动效，不提供自动全部开完按钮。

开包、比较、选五人与补强候选每排五张缩略卡，只显示真实海报和总评；图鉴每排四张。点击海报查看完整卡牌，选择按钮独立。原卡面三维不变，既有非铜卡的第一个常用特工标为唯一招牌，铜卡沿用原有无招牌设计。

八阶段依次为启点赛、大师赛、第一赛段常规赛、季后赛、大师赛、第二赛段常规赛及入围赛、季后赛、冠军赛。每个参赛阶段择一场实际合法且隐藏实力尽量接近的对局正式执教；其他比赛快速推演。进入总决赛额外正式执教 BO5，三图获胜即结束。其他正式场保留 BO3；后台按该赛事真实 BO3 / BO5。

赛事引擎模拟前置比赛，再等待玩家实际结果，随后推进全部后续比赛。CN 启点赛三败、季后赛双败，按剩余机会决定出局。大师赛包括十二队、八队瑞士轮、四位区域冠军直通与八队双败。冠军赛为四区各四席、GSL 分组和双败。第二赛段前两名直通，积分席位从其余队伍中选取，去重；按常规赛每胜及实际阶段名次记冠军积分。

大师赛瑞士首轮执行不同赛区二号对三号种子；后续按同战绩配对，不重复交手。区域冠军抽取次序后自动挑选瑞士晋级对手，AI 倾向较弱对手，玩家代理按已确认的实力接近偏好选择。其他赛区启点赛保护 2025 冠军赛四队轮空；CN 初始签位对照 2026 实际记录。采用制作时阵容重新模拟全年，不复制现实赛果。

两次大师赛结束后各投放一个十张补强包，没晋级也发放；逐张揭晓，确认五人后不可召回本次离队卡。七张图池只在第一、第二赛段开始前各随机换两张，九图候选保留批准名单。

比赛：七图 BP / 选边 → 每图选特工 → 首图安排攻防各五类优先级 → 逐分短报 / 合法窗口调整 → 单图、系列赛与赛事结算。后续地图沿用战术。快速选英雄计算五人不重复特工的整体搭配，考虑个人熟练、招牌、地图与职责覆盖，可手动改选；适配分是游戏启发式评分，不是职业赛事胜率数据。

总决赛由胜者组队伍选择 A / B 并连续禁两图，再交替选图；败者组没有两禁权。普通 BO5 与 BO3 分别使用对应禁选和决定图选边权限。赢两图 / 三图后不显示未进行地图的结果；夺冠有独立奖杯反馈，并写入实际参赛荣誉。

每图常规双方各两次战术暂停，整个加时各一次；谁发起只扣谁的次数，双方均可调整。中场免费调整。自动播放和快进遇到中场、对方暂停会停下等玩家操作；观看暂停不扣额度也不能改战术。加时逐分交换攻守，领先两分获胜。普通分留阅读时间，可切速度或快进。

队伍羁绊 / 状态 / 熟练，教练战术 / 临场 / 声望，地图积累统一显示 0–100。战术优先级、英雄适配、队伍与教练属性、继承地图分参与赛果计算。成长按实际回合、地图、比赛与参赛事实自动记账，重复结算不重复奖励。熟识跨同一选手版本共享，荣誉按实际参赛版本记录，离队者保留既得荣誉。下一年重新抽卡，继承生涯积累。

## 实现与数据边界

- 新征战正式与快速比赛调用同一 seeded 回合赛果模型，替换固定展示赛果。右侧普通章节仍为独立界面样例，两个 BO5 决赛预览由真实签表和固定种子生成。
- 当前为队伍层面概率模拟，经济和战术执行有所简化。尚未连接引擎目录中的精细移动、交火、技能和视线模拟，不能称为完整空间战斗引擎。
- 九图 BP 海报与比赛静态俯视图来自 [Riot 地图官网](https://playvalorant.com/en-us/maps/)，本地记录来源、哈希和“几何未验证”。俯视图可放大；精确导航、墙体、视线、多层与特殊机制待逐图制作，没有虚构选手移动。
- CN 94 个卡版本、原三维、英雄池与钻卡赛事版本保持不变。现有抽卡函数提供初始 5 / 15 / 30 / 50%，两次补强 7.5 / 22.5 / 45 / 25% 与 10 / 30 / 60 / 0%。
- 原批准的 50 队使用制作时阵容。TL 的 GSR、GX 的 tomaszy 缺对应卡；海外挑战者十二席已有真实队名但待补阵容，以明示中性先验暂代。不能视作完整全球内容；教练初值、阵容期间地图战绩与长期平衡待标定。
- 格式参考 [2026 官方手册](https://valorantesports.com/en-US/season/115571062868511862/handbook/)，CN 地区差异对照比赛记录。非 CN 入围赛通用拓扑、重模拟赛年的分组和最终同分 BO1 后备规则仍是明确的游戏处理，未还原全部地区逐项签位细则。
- 没有替换游戏目录的业务存档或删除旧工程入口；精细引擎与统一业务存档正式整合待推进。联机、自选组队保留后续提示。
