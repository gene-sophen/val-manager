# 正式征战前端

当前版本 **v0.21**，以手机 PWA 为优先，统一黄金比例选手卡；单张轻触揭晓与十连高光共用四档品质动效，初始三包可逐包体验或直接查看。推荐行动帮助新玩家推进，收藏可连续查看卡面，比赛固定比分并将执教操作收至底部。入口为[index.html](index.html)，与[手机PWA](https://gene-sophen.github.io/val-manager/)使用同一运行代码。

选择CN主队→三包逐张或快速开卡→选一包选五人→地图BP/特工/攻防排序→比赛暂停与中场执教→阶段结算和两次补强→赛年收藏、熟识、荣誉与继承。

当前界面提供任务式首页、具体继续操作、返回现场、选择理由与代价、战术对照和实际执行反馈。比赛使用空间引擎与关键分回放；非关键分可看战报，默认2×。旧存档继续按冻结行为版本恢复。

主导航在比赛和设置页常驻；自动推进与回放倍速分开，计算中可以停止后续推进；每张地图均确认特工和攻防方案。设置首屏提供已确认的存档位置与备份入口，可导出不含存档的布局诊断。iQOO Neo10 / OriginOS 6 真机桌面启动待验收。

## PWA 更新

网页和主屏幕安装版使用相同的入口、Service Worker 与本机存档。新版 Service Worker 完整下载必要的页面、脚本和样式后等待安装，旧页面在更新期间继续使用旧版缓存，避免两个版本混用。

在“设置 → 检查更新”发现新版本后，选择“保存并更新”。应用先完成本机存档写入，再激活新版并刷新；仅关闭网页、划出后台或重新打开，不保证切换仍在等待安装的版本。版本号与缓存标识必须随每次发布更新。

离线资源分为必要界面与按需缓存的选手、地图图片。更新后可以离线打开必要界面，尚未加载过的图片仍需联网一次。通过浏览器“保存网页”得到的本地 HTML 或 `file://` 文件不是可更新的 PWA，应从原网址重新安装到主屏幕；不要清除站点数据，以免丢失未导出的存档。

资源分别位于本目录、[共享资源](../共享资源/README.md)、`游戏/`和`素材库/`。不要复制出新的正式版本目录；迭代通过Git提交与PWA版本号管理。

本地启动方式见[根目录说明](../../../README.md)。发布命令为 `node 游戏/tools/build-pages.cjs`，只使用当前源码与必要资源；开发总览和地图复核页仍留在本目录，独立预览不会覆盖自己的征战。
