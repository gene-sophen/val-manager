# 正式征战前端

当前版本 **v0.26**，以手机 PWA 为优先，保留明亮教练战术室、深色比赛直播间与分层结算。开包组队、整场备战和页内转会减少重复确认；连续模式自动衔接真实赛果，手动模式仍保留决策点。首页 HTML、脚本、样式与 Worker 统一按版本隔离缓存。成长幅度本轮未调整。入口为[index.html](index.html)，与[手机PWA](https://gene-sophen.github.io/val-manager/)使用同一运行代码。

选择CN主队→逐张或快速揭晓三包→在同页选一包并组成五人→地图BP→整场特工与攻防方案→比赛暂停与中场执教→自动衔接赛程和两次转会→赛年收藏、熟识、荣誉与继承。

当前界面提供任务式首页、具体继续操作、返回现场、局部职责建议、战术对照和实际执行反馈。比赛使用空间引擎与关键分回放；非关键分可看战报，默认2×。旧存档继续按冻结行为版本恢复；没有整场方案的旧比赛保留逐图恢复路径。

主导航在比赛和设置页常驻；自动推进与回放倍速分开，计算中可以停止后续推进。连续模式沿用已确认的整场方案，半场与双方战术暂停保留决策；手动模式不自动离开结算页。设置首屏提供已确认的存档位置与备份入口，可导出不含存档的布局诊断。iQOO Neo10 / OriginOS 6 真机桌面启动待验收。

## PWA 更新

网页和主屏幕安装版使用相同的入口、Service Worker 与本机存档。新版 Service Worker 完整下载必要的页面、脚本和样式后等待安装，旧页面在更新期间继续使用旧版缓存，避免两个版本混用。

在“设置 → 检查更新”发现新版本后，选择“保存并更新”。应用先完成本机存档写入，再激活新版并刷新；仅关闭网页、划出后台或重新打开，不保证切换仍在等待安装的版本。版本号与缓存标识必须随每次发布更新。

离线资源分为必要界面与按需缓存的选手、地图图片。更新后可以离线打开必要界面，尚未加载过的图片仍需联网一次。通过浏览器“保存网页”得到的本地 HTML 或 `file://` 文件不是可更新的 PWA，应从原网址重新安装到主屏幕；不要清除站点数据，以免丢失未导出的存档。

资源分别位于本目录、[共享资源](../共享资源/README.md)、`游戏/`和`素材库/`。不要复制出新的正式版本目录；迭代通过Git提交与PWA版本号管理。

本地启动方式见[根目录说明](../../../README.md)。发布命令为 `node 游戏/tools/build-pages.cjs`，只使用当前源码与必要资源；开发总览和地图复核页仍留在本目录，独立预览不会覆盖自己的征战。
