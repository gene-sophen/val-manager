# 正式征战前端

当前版本 **v0.8**。入口为[index.html](index.html)，与[手机PWA](https://gene-sophen.github.io/val-manager/)使用同一运行代码。

选择CN主队→三包逐张开卡→选一包选五人→地图BP/特工/攻防排序→比赛暂停与中场执教→阶段结算和两次补强→赛年收藏、熟识、荣誉与继承。

当前界面提供任务式首页、具体继续操作、返回现场、选择理由与代价、战术对照和实际执行反馈。比赛使用空间引擎与关键分回放；非关键分可看战报，默认2×。旧存档继续按冻结行为版本恢复。

资源分别位于本目录、[共享资源](../共享资源/README.md)、`游戏/`和`素材库/`。不要复制出新的正式版本目录；迭代通过Git提交与PWA版本号管理。

本地启动方式见[根目录说明](../../../README.md)。发布命令为 `node 游戏/tools/build-pages.cjs`，只使用当前源码与必要资源；开发总览和地图复核页仍留在本目录，独立预览不会覆盖自己的征战。
