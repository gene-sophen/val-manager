# 金卡特性池与特性方向分配

> 阶段：方向设计（只定触发场景与强化对象，具体数值后续再定）
> 依据：设计文档 2.6 —— 通用特性为卡面可见的公共词条池，条件触发的属性增益，同一词条可出现在不同选手身上
> 与暗属性的边界：特性 = 可见、固定、标准化增益；触发器 = 隐藏、随机 roll、个体差来源（见文档 3.7）

---

## 一、特性池（13 个方向）

| 特性 | 触发场景（方向） | 强化对象 | 适合人群画像 |
|---|---|---|---|
| 首杀机器 | 首杀对决 | 枪法 | 高首杀率突破手（FK/回合 ≥0.15） |
| 快刀手 | 执行 Rush | 枪法+协同 | 进点型决斗 |
| 重炮手 | 连杀/多杀回合 | 枪法 | 高爆头率、高 KMAX 火力点 |
| 大场面先生 | 赛点/关键局 | 三维 | 有 key 局人设的明星 |
| 残局大师 | 残局判定 | 意识 | 低首死、高 KDA 的存活型选手 |
| 孤胆英雄 | 1vN / 队友先阵亡 | 意识+枪法 | 兜底位（本期未分配，留池） |
| 黏合剂 | 技能 Combo 判定 | 协同 | 高助攻率的功能位 |
| 补枪手 | 补枪/换杀判定 | 协同 | 高助攻+高存活的二线火力 |
| 定海神针 | 连败止损/团队士气 | 三维 | 指挥（IGL） |
| 老六 | 防守反绕后/埋伏 | 意识 | 哨卫、自由人、lurker |
| 铁壁 | 防守回合 | 意识+协同 | 主防哨卫 |
| 读心者 | 识破假打/信息获取 | 意识 | 信息位先锋、阅读型指挥 |
| Eco 刺客 | Eco 局 | 枪法 | 本期未分配，留池 |

**分配原则**：
- 数据优先：FK/回合（首杀）、FD/回合（存活）、HS%（精度）、KMAX（连杀）、A/回合（团队）——全年合并数据
- 人设兜底：数据相近时按赛场人设（如 nAts/Less 的 lurker 属性、康康/aspas 的关键局属性）
- 池内复用：同一特性多人持有是正常的，个体差异由暗属性触发器承担
