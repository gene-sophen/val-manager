## 0. 核心体验与前置约定

玩家组建五人队，作为教练进行地图 BP、逐图选英雄、赛前布置和有限临场调整，观察选手自主比赛，争取赛年成绩。成长来自比赛结果、队伍磨合与教练积累，不增加赛后选技能、领取战术卡或手动培养选手的操作。

一次征战覆盖一个赛年。每次新征战重新抽取本次可上场的选手；永久图鉴不直接替代随机开局。自选组队和联机仍是先前提出的模式方向，本次未确定其继承、公平性与开放条件，不沿用旧提案中的费用制度。

### 卡包与五人阵容（已确认）

| 节点 | 包数 × 每包张数 | 钻 / 金 / 银 / 铜 | 使用方式 |
|---|---|---|---|
| 开局 | 3 × 10 | 5% / 15% / 30% / 50% | 三包全部看清，选其中一整包，再从该包十人中选五人；不能跨包拼队 |
| 第一届大师赛结束、第一赛段前 | 1 × 10 | 7.5% / 22.5% / 45% / 25% | 补强现有五人，可不换，也可换掉全部五人 |
| 第二届大师赛结束、第二赛段前 | 1 × 10 | 10% / 30% / 60% / 0% | 同上 |

- 无替补，正式阵容始终五人；补强换人数量不限。
- 两个补强节点按整个赛年日程触发，未入围大师赛也获得；不因跳过世界赛漏发，不因跳过多个节点多发。
- 卡牌设计不变：固定枪法 / 协同 / 意识、品质、英雄池及原有特性体系；同一选手不同版本不能同时上场，每队最多一钻。
- 包内不重复规则继续细化为卡版本不重复的建议。已验证当前单赛区卡池每区仅五张钻卡，十张不放回包至少有五张不同选手普通卡，能组成合法五人；无需额外补包。混池或卡池扩充需重验，详见[卡包规则](抽卡系统设计.md)。不能以未披露保底暗改上述概率。
- 不增加薪资、阵容费用、重复升星或永久提高选手基础三维的机制。
- 开出的全部卡解锁图鉴，包含初始三包中未选的卡；图鉴不等于上场资格。初始选队和补强一经确认，只保留当前五人的上场资格。其余人选不留作替补，不留到下个补强窗口，已换走的卡不能从历史名单换回。

## 1. 三层三维与命名

**已确认：**选手个人协同与队伍羁绊关联但独立。协同体现个人与队友配合时的能力；羁绊体现这五人的共同关系与磨合，换人会改变羁绊。队伍三维随比赛过程、赛后及换人变化；教练三维可跨征战继承，并随表现上升或下降。

**2026-10-03 已确认名称与分工：**

| 层级 | 三维 | 含义与边界 |
|---|---|---|
| 选手（已确认） | 枪法 / 协同 / 意识 | 固定个人能力，临时发挥不改写卡面基础值 |
| 队伍（已确认） | 羁绊 / 状态 / 熟练 | 关系与磨合 / 当下发挥 / 对战术体系的掌握 |
| 教练（已确认） | 战术 / 临场 / 声望 | 布置能力 / 读局与调整能力 / 执教认可度；可跨局更新 |

用户已确认：“熟练度”使用两字名“熟练”；教练由“经验”调整为“临场”；队伍将心态与手感合为“状态”。此次确认关闭名称与分工问题，具体成长系数仍为待平衡参数，不代表引擎已实现。

队伍熟练描述整体体系掌握，个人协同描述个人配合能力；地图分描述特定地图表现，三者不能用同一加成重复计算。暗属性可借三层数值触发或影响发挥，具体载体与原有触发器的衔接仍未定，不能直接删掉或声称已实现。

## 2. 赛年流程与阶段压缩

**已确认的顺序：**

启点赛 → 大师赛① → 第一赛段常规赛 → 第一赛段季后赛 → 大师赛② → 第二赛段常规赛 → 第二赛段季后赛 → 冠军赛。

每个阶段只做一次由玩家正式参与的比赛，其他比赛快速结算，给出排名和资格结果。没有季后赛或世界赛资格则跳过相应比赛节点，进入后续有资格参与的节点；补强按前述两个固定节点投放。

**正式对局选择方向已确认：**选择隐藏战力相近的对局，使教练在过程中的决策能够影响表现，并据此评估队伍整体强度。对手应保有自己的实力，不能为了保证接近而暗中同步增强或削弱对手。隐藏战力用于内部匹配与评估，不新增要求玩家维护的可见属性。

**阶段划分已确认：**以上八个节点各至多一次正式 BO3，全部晋级时至多八场。没有季后赛或世界赛资格则跳过相应节点。

**正式比赛用于校准阶段表现，已确认。**先依据阵容、队伍和教练能力估计隐藏战力，选取实力相近的对手；再以正式 BO3 的表现评估实际发挥，将执教效果计入本阶段其他比赛的快速结算。具体评估公式待设计，不简单以一场胜负直接判定整个阶段。

实现时需控制：考虑对手实力及比分、过程表现，限制单次随机爆冷对评估的影响；不改写选手卡基础能力；区分比赛自然成长与阶段表现校准，避免同一份收益算两次。已给出固定种子隔离预演、合法路径择近、提交前缀、正式后重新模拟的具体方案，详见[赛程专题](../02_专题设计/阶段实力评估与赛程结算.md)。不再保留独立评估赛选项。

快速结算不要求玩家逐场选英雄或干预，**已确认同样计入成长**。建议复用同一套球队、战术和地图规则，以自动教练处理决策；展示赛果、排名、晋级依据。已结算赛果不因之后一场比赛的表现被回溯改写。

这是游戏化压缩设计，不宣称“一阶段一场”“全部 BO3”或随机地图轮换是现实 VCT 原规则。具体地区、年份、资格分配和同分规则仍须单独冻结。

## 3. 一次正式比赛与观赛节奏

**已确认：**正式比赛使用 BO3，先进行地图 BP；每张地图开打前由玩家为五名选手选择英雄。常驻地图池为七张，赛段间随机替换两张。

单场流程：地图 BP → 第一图选英雄与开局战术 → 自动逐回合推演、战报与关键回合观赛 → 中场及可选暂停调整 → 单图结算 → 下一图选英雄与布置 → 一方取得两图胜利，BO3 结算。

- 比赛开始、中场与暂停允许调整战术；玩家自行决定何时暂停，对手也根据局势暂停并调整战术比重。沿用前轮提出的规则口径：每队每图常规两次、整个加时一次，常规剩余额度不带入加时；不能每轮加时刷新一次。任一方暂停，双方都可以调整，只扣发起方额度。
- **观赛节奏已确认：**关键回合默认进入 2D 沙盘，可加速或跳过；普通回合自动显示比分与一句主要胜负原因，保留阅读和请求暂停的时间。
- 每个回合根据实际比赛情况合理结算队伍三维，无须强迫三维每分都产生非零变化。变化速度、幅度与恢复规则由后续平衡设计确定。
- 玩家不操纵走位、瞄准、技能释放；这些由选手引擎执行。
- 不要求每分点击“继续”。普通回合自动播放；玩家随时可请求战术暂停，在下一合法回合间隙生效，不能回滚已经公布的赛果。赛前、中场及任一方战术暂停时进入调整窗口。
- **播放暂停与战术暂停分开：**播放暂停可用于阅读战报，不消耗战术暂停，也不开放修改战术的权限；只有合法执教窗口可以更改战术排序。
- 战术设置跨回合持续，直到合法调整窗口改变，不按每分重复填写。

**建议的普通回合信息格式：**当前比分 + 一句主要胜负原因 + 关键表现 + 属性净变化。例如“5:7｜A 点进攻被交叉火力拦截，残局未能下包｜状态下降”。具体数值一律来自真实结算，不凭解说生成原因。

**建议的关键回合标准：**手枪局、赛点和加时为赛前可识别的关键回合；意外残局与高光可在发生后提供回放。回放中的暂停不能影响已发生的结果。2D 展示与文字战报使用同一份事件记录。

**加时已确认采用正式规则：**需领先两分获胜。精确实现不能写成“只要连续赢两回合就结束”：例如 12:13 后连拿两分成为 14:13，仍未领先两分。常规建议采用半场 12 回合、先到 13 分，12:12 进入轮流攻防的加时；不采用旧的一局定胜负。

**地图 BP 已确认采用正常比赛规则。**已核对 2026 VCT 官方通用规则第 4.6.8 节：高种子选择成为 A 或 B，无种子时随机决定选择权；A 禁、B 禁、A 选图一/B 选边、B 选图二/A 选边、A 禁、B 禁，剩余图三/A 选边。这里采用普通 BO3 流程，不能自动混入双败总决赛的特别待遇。

来源：[2026 VCT Official Competition Ruleset](https://cdn.sanity.io/files/dsfx7636/news_live/f600a428dbcb54cff5814750f4c4be2b699d7934.pdf)，规则 4.6.2、4.6.8 与 6.1；核对日期 2026-10-01。该规则的暂停额度为每队每图常规两次，加时一次，常规额度不带入加时。游戏无需强迫玩家实际等待官方的暂停时长。

**双方暂停时的操作边界已确认：**任一方发起，双方都可重排战术。玩家也可不修改、直接继续，不增加强制确认每项参数的操作。对手调整不能偷看玩家本次尚未公开的排序，双方确定后才用于后续推演。

## 4. 擅长地图与跨局继承

**已确认：**队伍有擅长和不擅长的地图；地图可用战力分量化，地图胜负后发生变化。继承教练积累的部分，当前五人的地图磨合随换人调整。

每张地图显示一个地图分，表达这一地图上的准备和适应优势。内部区分教练历史积累与当前五人的地图磨合；教练部分跨征战保留，队伍部分随换人调整。拆分比例及变化公式留给数值设计，不要求玩家分别操作两项数值。

- 地图分影响地图相关的执行与适应，不能与枪法等通用能力无差别地重复相乘。
- 随机换出的地图保留教练历史积累；重回地图池时不会因曾经退出而清零，当前阵容部分按届时成员与磨合记录计算。
- **轮换时点已确认：只在大段调整。**启点赛开始前随机生成七图；第一赛段开始前随机替换两图；第二赛段开始前再随机替换两图。大师赛、常规赛转季后赛、冠军赛不单独轮换。每次从轮换前池外抽两个不同地图，移出两图，始终保持七图；初始生成后不再额外轮换一次。
- 总候选地图集合、对手地图分、同一征战是否共用轮换、地图分变化算法均待定。建议同一赛事双方共用地图池，轮换按全局赛历推进，跳过参赛资格不会冻结世界地图池。
- 七图可玩需要七图对应的推演与显示数据；包含轮换至少还需两张池外可用地图，不能只有九个名字、仅一图能推演。

## 5. 比赛内外的属性结算

**已确认：**比赛内每分队伍三维变化，比赛结束后队伍三维与教练三维也有变化。教练继承是可升可降的当前执教档案，不是只增不减的经验仓库。

**建议的结算分层：**

| 时点 | 处理内容 | 防止重复的要求 |
|---|---|---|
| 每回合后 | 过程表现引起的队伍状态、磨合变化 | 每个回合仅入账一次 |
| 单图后 | 地图胜负引起的地图分变化 | 不重复发放整场结果收益 |
| BO3 后 | 整场成果引起的队伍及教练变化 | 区别于已累计的回合变化 |
| 补强确认后 | 按新五人关系重算羁绊等受影响部分 | 保留未更换成员的已有关系 |
| 开包时 | 开出的卡解锁图鉴，不要求上场 | 初始未选包的卡也记录；重复不产生战力收益 |
| 比赛/赛事结束 | 保存实际出场名单，记录该选手对应成就与收益资格 | 正式与快速比赛一致；换人不删除历史参赛记录 |
| 赛年结束 | 更新继承档案，按参赛记录汇总熟识与荣誉，汇总图鉴 | 同一赛年重复载入不重复领取；不能只给年末五人，也不能把新成员未参加的比赛算给他 |

需要分别规定状态跨图/跨场恢复、羁绊与熟练的速度、上下限及结果归因。避免连败导致状态下降、下降继续促成失败的过强循环；也避免所有数值同向增长，使换人和战术判断失去意义。具体范围与权重通过平衡验证确定，本稿不虚构已验证数值。

## 6. 战术克制与执行倾向

**已确认：进攻五套、防守五套，分别使用优先级排序。**沿用强攻 / 控图 / 诱导 / 渗透 / 反制五个方向，但攻防具有不同的执行内容，显示名称可以不同。玩家排列当前一侧五套战术的执行优先级，不手动填写比例；引擎结合优先级和当下局势决定具体执行。暂停时可重排，对手教练也能根据局势调整自己的比重。

五类之间可设置不同程度的优势、劣势与中性关系，不必局限于每类只克制下一类的单环。克制提供优势而不保证获胜，最终仍由选手、阵容和即时发挥共同决定。此前“三类战术”和“主打法加偏向预设”的建议撤回。

具体攻防名称、执行行为与克制矩阵由下一步战术设计给出。排序代表优先考虑，不是第 1 回合执行第 1 类、第 2 回合执行第 2 类，也不意味着第一类永远执行。内部权重由规则转换，合法性、已知信息、人数和经济等决定可执行选择。对抗关系按进攻五套与防守五套形成 5×5 组合，不把同一个五行环同时机械套在双方身上。

克制效果应落到接触时机、信息判断、站位与协同行动等可见结果。若已有空间行为自然带来优势，不再额外叠加同一份克制百分比。必须验证无绝对优势策略，且教练判断仍有作用。

对手倾向建议通过已发生的回合证据逐步呈现，不直接泄露其下回合选择。玩家需要知道“对方近期如何打”“自己的调整何时开始生效”。进攻、防守分别保存排序，中场可沿用预设或调整，不要求把另一侧的排序重新填写。

## 7. 成长和干预范围

**已确认：**比赛是战术积累与数值继承的过程；地图 BP 与战术调整是主要干预，选英雄和补强组队保留；数值改变体现执教成果，赛年成绩是最终收获。

新版取消旧提案中的战术卡获得、开局专长选择、赛后三选一成长、阶段成长槽、额外随机备战事件选择及收藏点购买卡包等操作。它们不再是实施前置条件。内部能力成长由比赛自然结算，不包装成另一层要领取和装备的卡牌。

建议英雄选择支持推荐阵容与沿用设置，玩家可修改；地图 BP、开局和中场才是固定决策停点，暂停由玩家按需要使用。所有队伍数值默认自动更新，界面给变化原因，不要求加点。

## 8. 赛年收获：图鉴、选手关系与荣誉

**已确认：**开包都解锁图鉴，不以入选阵容为前提。选手参加哪些比赛，就获得对应的成就与收益；快速结算也计入成长。熟识收益与教练声望和赛年成绩有关，影响后续组队的基础羁绊。真实同队选手共同上场也提高羁绊。卡牌记录夺冠等局外成就，荣誉不改变局内强度。

**换人收益边界已确认：**离队不取消之前实际参赛产生的收益，不论这些收益是否已经发放。例：选手随队获得大师赛冠军，之后被换走，仍保留该冠军荣誉及对应熟识收益；不获得离队后未参加赛事的收益。新队员也不获得加入前比赛的收益。年终汇总必须查询历史参赛名单，不能只看最终五人阵容。

建议拆清三种来源：

- 熟识：教练与这一选手长期共事的积累，新征战组队时提供基础关系。
- 原队关系：卡牌指定的真实赛季战队中共同效力的关系，不随实时转会自动变化。
- 当届磨合：这五人在当前赛年共同比赛形成的关系，补强时按受影响成员改变。

三者共同形成队伍羁绊，不分别各加一次同样的全队战力。**已确认：熟识持续累计，提供的基础羁绊收益逐渐递减。**具体曲线留给数值设计，避免永久关系数值最终压过新抽到选手的差异；这一点与允许上下波动的声望不同。

图鉴与荣誉都是持久记录；熟识通过羁绊影响局内，不能把全部收藏内容统称为纯外观。**2026-10-03 已确认：同一真实选手的普通卡、钻卡及其他版本共享熟识；荣誉只记录在实际参赛的卡版本上，不跨版本自动复制。**熟识只影响基础羁绊，不改写卡面三维，也不赋予未抽到卡的上场资格。原队快照及声望、年度成绩如何作用于各选手实际参赛收益，见结算专题。

### 剩余事项的性质

- **系统细化首轮已补齐：**阶段校准到自动教练参数、真实路径选场、攻防十套与暂停细则、0–100 初值与恢复、地图分拆分、熟识曲线及历史参赛结算均有具体草案。已做数学和简化签表检查，尚未接入真实引擎验收，不能把单次表现当成确定的长期实力。
- **内容配置已有规格，仍需落数据：**2026 赛制、可选 CN 主队、其他赛区后台模拟和混合 BO3/BO5 已确认。对手阵容与实力参考采用制作时的数据版本，一局开始后冻结；现有选手卡固定三维不变。九图候选库仍为建议，对手快照与地图资产尚未制作完成。见赛程专题第 8、10 节，不能把配置建议当作官方全量复刻已完成。
- **三维与关系归属已确认：**队伍“羁绊 / 状态 / 熟练”、教练“战术 / 临场 / 声望”；同一真实选手跨版本共享熟识，具体卡版本分别记录荣誉。原队关系按固定赛季快照，不随实时转会修改历史。
- **边界规则已给出默认：**当前单赛区包内按卡版本去重，人数合法性已证明；新抽到离队者可以按新招募处理；主动放弃只结已发生收益；声望采用收益来源对应的开赛快照。这些属于本轮设计细化，未冒充用户逐字定案，具体见卡包与收益专题。

### 已发现的主要设计风险

1. 阶段校准已采用，具体评估仍需验证：必须让玩家知道执教影响哪些结果，限制单次随机爆冷的放大，保持其他对手真实强弱差异；不可暗改比赛保送或靠调平对手掩盖阵容成长。
2. 若一次阶段会展示三图，八阶段最多二十四图，仍可能较长：普通回合自动播放、关键回合可跳过、英雄推荐与暂停可选是低操作量的必要部分。实际赛年时长需试玩测量。
3. 地图分、熟练、个人协同含义接近：要分别作用于地图适应、体系掌握、个人配合，避免重复加成和多个等价进度条。
4. 熟识对羁绊的递减收益方案已采用，但曲线需验证，避免旧熟人收益仍然过高而让玩家放弃补强。
5. 胜负同时改变状态、地图分和教练能力可能强化连胜连败：不同时间尺度、变动上限与恢复规则需共同验证。

实施顺序建议：

1. 基于已确认规则建立新规则版本；先细化阶段表现评估、攻防战术和历史参赛结算方案，再冻结赛事与地图内容配置。具体增减幅度作为可调参数，已关闭问题不重复确认。

5. 补齐地图推演和 2D/短报表现，验证自动播放中能及时暂停，以及可跳过、可续玩。
6. 完成开包图鉴、按参赛历史归属的熟识与荣誉、年终汇总及下一轮继承，处理旧存档，不覆盖旧记录。
