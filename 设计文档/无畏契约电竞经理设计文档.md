# 无畏契约电竞经理 · 设计文档

> 版本：v3（框架定稿）
> 范围：选手卡系统、暗属性系统、战斗计分系统、单局比赛流程、抽卡系统
> 说明：本文档只包含系统框架与数值规范，具体选手卡内容由后续单独填充。

---

## 一、游戏概述

### 1.1 定位

参考《英雄联盟电竞经理》的核心框架（选手卡牌 + 赛前战术博弈 + 自动模拟比赛），结合无畏契约（VALORANT）的玩法特性（特工 / 枪械经济 / 地图轮换 / 残局）设计的电竞经营模拟游戏。

### 1.2 核心循环

组建战队 → 赛前布置（选图 / 阵容 / 战术）→ 观看或跳过自动模拟比赛 → 获得资源 → 抽取选手 → 冲击更高联赛

### 1.3 复杂度控制原则

- 卡面只展示三维主属性，复杂计算全部隐藏在水下
- 战斗每个判定环节只调用 1~2 个主属性，规则透明可解释
- 无局外养成线（无等级 / 无特训 / 无升星），卡牌数值出厂固定
- 深度来源：暗属性触发器的个体差 × 四档品质 × 英雄池配队
- 不含转会市场、赛季更新、设施经营等重度经营模块（后续版本再议）
- PVP 预留接口，后置设计

## 二、选手卡系统

### 2.1 卡面字段

卡面只展示以下内容，其余信息全部隐藏：

| 字段 | 说明 |
|---|---|
| 选手 ID | 真实职业选手 ID |
| 所属战队 | 按确定赛季快照写死，后续随转会期更新 |
| 位置 | 决斗 / 先锋 / 控场 / 哨卫 / 自由人 |
| 三维数值 | 枪法 / 协同 / 意识 |
| 品质 | 钻 / 金 / 银 / 铜 |
| 英雄池 | 按选手真实使用取 2~3 个特工，银卡及以上含 1 个招牌英雄 |
| 特性 | 金卡及以上展示（通用特性） |
| 明星时刻 | 仅钻卡展示（专属机制） |

### 2.2 三维主属性

| 属性 | 定义 | 战斗中考察的场景 |
|---|---|---|
| 枪法（AIM） | 正面火力 | 首杀对决、常规对枪、Rush 质量 |
| 协同（SYN） | 团队执行 | 补枪、技能 Combo、战术执行成功率、Eco 纪律 |
| 意识（SEN） | 局面判断 | 残局、反绕后、转点决策、假打识破 |

**设计原则**：三维是战斗中唯一的"货币"。所有系统（暗属性、战术、枪械、熟练度）最终都折算成对三维的修正或对战力的修正，不存在平行数值体系。

### 2.3 品质分级（四档）

| 品质 | 三维总和 | 单维区间 | 英雄池 | 招牌英雄 | 特性 | 明星时刻 |
|---|---|---|---|---|---|---|
| 铜 | ~130 | 30~62 | 2~3 个 | 无 | 无 | 无 |
| 银 | ~185 | 44~76 | 2~3 个 | 1 个（×1.1） | 无 | 无 |
| 金 | ~240 | 58~90 | 2~3 个 | 1 个（×1.1） | 1 个通用特性 | 无 |
| 钻 | ~250 | 66~90 | 2~3 个 | 1 个（×1.15） | 1 个通用特性 | **1 个专属机制** |

> 单维区间整体跨度 30~90，档间有重叠（弱金可低于强银），档内差异拉大，个体风格更鲜明。

**递进逻辑**：每升一档恰好解锁一层玩法——

- **铜**：纯数值白板 + 英雄池，保证基础配队能力，填充卡池与新手期
- **银**：招牌英雄 → 解锁数值支点（1.1 倍招牌系数，值得围绕建队）
- **金**：通用特性 → 解锁机制增益（条件触发的属性词条，从通用特性池中分配）
- **钻**：**明星时刻** → 解锁专属机制（见 2.8），是收藏与强度的双顶点

> 注：英雄池按选手真实赛场使用取 2~3 个（统一规格，不按品质区分数量），品质差异体现在"数值 → 数值支点 → 机制增益 → 专属机制"的层层递进。配队广度由英雄池保证，配队深度由品质提供。

### 2.4 位置模板

同品质内三维总和一致，差异通过配比体现选手风格（配比即人设）：

| 位置 | 配比倾向 |
|---|---|
| 决斗 | 枪法 +12 |
| 先锋 | 协同 +12 |
| 控场 | 均衡偏意识 |
| 哨卫 | 意识 +12 |

### 2.5 英雄池与招牌英雄

- 英雄池按选手真实使用取 2~3 个特工，不设入门/熟练分档
- 银卡及以上含 1 个招牌英雄（选手最常用的特工），招牌英雄战力系数 ×1.1（钻卡 ×1.1~1.15），其余特工系数为 1.0
- 招牌英雄系数作为乘算参数进入个人战力公式
- 特工池不做精简，与游戏原版特工保持一致（以选手真实使用的特工为准），每个特工带标签用于阵容协同判定

### 2.6 通用特性（金卡及以上）

通用特性是从公共词条池中分配的条件增益词条，卡面可见，同一词条会出现在不同选手身上。示例：

| 特性 | 效果 |
|---|---|
| 首杀机器 | 手枪局枪法 +12 |
| 残局大师 | 残局判定时意识 +15 |
| 黏合剂 | Combo 判定时协同 +12 |
| 快刀手 | Rush 执行时枪法 +8、协同 +8 |
| 老六 | 防守反绕后意识 +12 |

### 2.7 明星时刻（钻卡专属机制）

明星时刻是钻卡独有的**主动型高光机制**，不止于属性增益，而是能改写单个回合走向的专属演出事件：

- 每场比賽可触发 1 次（BO3 每图 1 次），在关键局面（残局、赛点、连败止损）自动点燃
- 触发时插入专属演出动画，本回合该选手战力获得大幅加成（建议 +25%~35%），并附带独特规则效果
- 明星时刻与选手真实赛场名场面绑定，一人一机制，不可出现在其他选手身上

**钻卡性质与配队限制**：

- 钻卡为**切面式传奇卡**：某选手在某届关键赛事的巅峰版本（如「2023东京大师赛 · ZmjjKK」），数值可参考赛事数据但允许高于实际表现
- 同一选手可有多个钻卡切面，切面之间数值与技能不同
- **同一选手的钻卡与普通卡不能同时上场；每队最多上场 1 张钻卡**（限制核心、防止强度膨胀）

示例：

| 选手类型 | 明星时刻 | 效果 |
|---|---|---|
| 狙击型决斗 | 「冥驹审判」 | 残局时触发：本回合意识 ×1.3，且对方无法触发任何事件 |
| 突破型决斗 | 「闪电进点」 | 执行 Rush 时触发：全队枪法 +15，Rush 克制判定必胜 |
| 残局型哨卫 | 「一人成军」 | 1vN 时触发：每多 1 名敌人，胜率惩罚减半 |

### 2.8 品质锚点原则

- 钻卡：国际冠军头衔或公认 TOP 级选手
- 金卡：各队核心首发
- 银卡：稳定首发 / 轮换
- 铜卡：新秀 / 替补 / 次级联赛上调选手
- 玩家凭赛事认知即可预判品质，学习成本为零；明星选手品质必须与其赛场地位相符

### 2.9 具体卡牌内容

> 见 `选手卡/` 目录：现役卡覆盖四赛区 2026 赛年（金 60+ / 银 / 铜，按全年数据 + 成绩生成），钻卡为切面式传奇卡（首发 20 张，见 `选手卡/钻卡人选构思.md`）。金卡特性方向见 `选手卡/金卡特性方向.md`。

## 三、暗属性系统（触发器）

### 3.1 定义

暗属性**不是固有数值**，而是「触发条件 → 主属性修正」的条件规则条目。平时完全沉睡，条件满足的瞬间生效，生效对象永远是三维主属性。

暗属性系统与品质系统**完全隔离**：低品质卡可以 roll 出优秀的触发器，高品质卡也可能拿到平庸的触发器。品质决定三维数值与英雄池下限，触发器决定个体上限与"剧本感"。

### 3.2 触发器结构

```
【触发器】= 触发条件 + 修正对象 + 修正方式 + 持续时间/次数
```

### 3.3 触发条件库

| 类别 | 条件示例 |
|---|---|
| 比分类 | 落后 3 分以上 / 赛点局 / 连胜中 / 连败中 |
| 回合类 | 手枪局 / Eco 局 / 上半场 / 下半场 / 加时 |
| 事件类 | 进入残局 1vN / 队友先阵亡 / 打出首杀后 |
| 战术类 | 执行 Rush 时 / 战术被克制时 / 防守被转点时 |

### 3.4 修正方式

- **加算**：直接 + 固定值（如 枪法 +10）
- **乘算**：按比例（如 意识 ×1.15）
- 持续范围：单回合 / 本图剩余回合 / 仅触发一次

### 3.5 触发器示例库

| 触发器 | 内容 | 战报评语（侧写透露） |
|---|---|---|
| 大心脏 | 赛点局 → 三维 ×1.12，单回合 | "关键局的他判若两人" |
| 慢热 | 上半场 → 三维 ×0.94；下半场 → ×1.06 | "下半场他终于醒了" |
| 复仇怒火 | 连败 ≥3 → 枪法 +8，持续至获胜 | "连败没有击垮他，反而点燃了他" |
| 残局猎手 | 进入 1vN → 意识 ×1.2，单回合 | "这个残局他处理得滴水不漏" |
| 团队基石 | 队友先阵亡 → 协同 +10，单回合 | "减员之后他扛起了队伍" |
| 顺风浪 | 领先 ≥3 → 三维 ×1.08；落后 ≥3 → ×0.95 | "他打顺了，也只会打顺" |

### 3.6 个体差与"识人"玩法

- 同名卡的同一触发器，roll 出不同修正幅度（如「大心脏」×1.08 ~ ×1.15）
- 玩家无法直接查看触发器数值，通过赛后战报评语推断
- 核心乐趣循环：抽卡 → 实战观察 → 识别极品 → 围绕其建队
- 重复卡处理：无养成体系，同名重复卡自动转为兑换货币；触发器更优的同名卡值得保留

### 3.7 与特性/明星时刻的边界

三个系统共用"条件触发"的表述，但职责不同，注意区分：

| 系统 | 可见性 | 来源 | 定位 |
|---|---|---|---|
| 通用特性（金/钻） | 卡面可见 | 固定，公共词条池 | 标准化的条件属性增益 |
| 明星时刻（钻） | 卡面可见 | 固定，一人一机制 | 改写单回合走向的专属演出事件 |
| 暗属性触发器（全品质） | 隐藏 | 抽卡时随机 roll | 个体差来源，决定同名卡的强弱 |

## 四、战斗计分系统

### 4.1 核心思路

战斗拆分为若干判定阶段，每个阶段有专属计分公式，把三维（含触发器修正后的生效值）换算为**战力值**，比较双方战力值 → 映射为概率 → 掷骰定结果。

### 4.2 完整回合流程

```
① 经济判定（确定枪械系数）
→ ② 触发器检查（比分/回合类条件，刷新生效三维）
→ ③ 战术抽取与克制判定
→ ④ 阶段一：队伍基础战力计算
→ ⑤ 阶段二：关键事件判定（事件类触发器在此点燃）
→ ⑥ 阶段三：战术对抗修正汇总
→ ⑦ 阶段四：回合胜负结算 → 更新比分与经济
```

### 4.3 阶段一：回合基础战力

```
个人战力 = (枪法×0.4 + 协同×0.3 + 意识×0.3)
        × 枪械系数（Eco 0.85 / 半起 0.95 / 全起 1.0）
        × 招牌系数（招牌英雄 1.1，钻卡 1.15，其余 1.0）

队伍基础战力 = Σ 5 人个人战力
```

位置微调：决斗位枪法按 0.5 计、哨卫位意识按 0.4 计。

### 4.4 阶段二：关键事件判定

| 事件 | 计分公式 | 概率映射 |
|---|---|---|
| 首杀对决 | 双方决斗位：枪法 × 手感系数 | 差值每 1 点 = ±1.5% 胜率 |
| 技能 Combo | 发起方：协同 ×1.2 + 配合位协同 | 与难度值比较定成功率，成功 +5% |
| Eco 翻盘 | Eco 方全队均值：协同 ×0.5 + 意识 ×0.5 | 基准 8%，随战力差浮动 |
| 残局 1vN | 存活者：意识 ×0.7 + 枪法 ×0.3 | 1v1 基准 50%，每多 1 敌 −18% |

### 4.5 阶段三：战术对抗修正

| 修正项 | 效果 |
|---|---|
| 战术克制 | 克制 +8% / 被克制 −8% |
| 读图识破 | 概率触发，对方战术修正清零 |
| 阵容协同 | 满足标签组合 +3% ~ +5% |

**战术克制三角**：

- 快攻 克 重防赌点，怕 前压反清
- 慢打 克 前压反清，怕 重防赌点
- 假打转点 克 重防赌点，与常规站位互有胜负

**阵容协同组合**（示例）：

- 双闪组合（2 个带闪特工）：Rush 战术时 +5%
- 铁桶阵（双哨卫标签）：防守方 +5%
- 信息链（2 个信息位）：慢打战术时 +5%

### 4.6 阶段四：回合结算

```
回合胜率 = 50%
        + (我方队伍战力 − 对方队伍战力) × 0.15%
        + 关键事件修正（首杀 ±6% / Combo +5% / 翻盘事件直接结算）
        + 战术对抗修正
最终钳制于 [12%, 88%] → 掷骰 → 本回合胜负
```

### 4.7 状态更新

- 连败：每连输 1 回合，全队临时 −2% 生效三维（受触发器调制），赢下回合后清除
- 连胜：3 连胜后 +2%（上限 +4%），防止滚雪球过大

## 五、单局比赛流程

### 5.1 赛前阶段（玩家操作，约 3 分钟）

1. **Ban/Pick 地图**（地图池 5 张）
   - BO1：各 ban 2 张，系统从剩余随机抽 1 张
   - BO3：轮流 ban/pick 出 3 张
   - 地图带标签影响战术收益（例：狭间图 Rush 收益 +3%；开阔长枪线图枪法权重 ×1.1；三点图转点收益 +3%）
2. **选择特工阵容**：从选手英雄池配置，系统提示可用协同组合
3. **布置战术权重**：攻防各分配百分比滑条（默认慢打 / 快攻 Rush / 假打转点 等）
4. **经济策略**：稳健型（钱不够 2900 则 Eco）/ 激进型（够 1900 即强起）

### 5.2 赛中阶段

- **观赛模式**：文字 + 简笔俯视小地图演出，每回合约 8~10 秒；关键事件（翻盘、残局、首杀）插入特写卡面动画
- **跳过模式**：直接出结果与战报
- **战术暂停**：每场 1 次（BO3 每图 1 次），效果：
  - 清除连败衰减
  - 临时调整战术权重与经济策略
  - 下一回合全队 +3%
- **换人**：BO3 图间可换 1 人（替补席 1 人）

### 5.3 结束与战报

- 13 胜制，平局加赛 1 局定胜负
- 赛后战报：比分曲线、关键事件回放、选手数据（首杀数、残局胜场、回合贡献值）
- 战报评语承担暗属性的"侧写透露"功能

## 六、抽卡系统（卡包制）

- **核心前提**：玩家只能使用自己开包获得的选手卡组队征战；卡包获取条件放宽
- **卡包**：只按赛区区分——CN / AMER / EMEA / PAC 四种包，每包 10 张卡
- **抽取规则**：从该赛区全部选手卡（金银铜钻）中等概率、不放回抽取，包内不重复；跨包可重复
- **稀有度**：不设权重与 UP，分布由池子构成决定（每包期望金约 1.5 张、钻约 0.5 张）
- **强度天花板**：每队限 1 张钻卡 + 同名钻/普通卡互斥，开包多出的高品质卡不叠加强度
- **免费获取**：比赛奖励 + 每日任务
- **每日任务示例**：赢 3 场、打出 1 次残局胜利、使用 1 次暂停（任务本身即机制教学）
- 细则与包大小论证见《抽卡系统设计.md》

## 七、系统自检

| 检查项 | 结论 |
|---|---|
| 单局时长 | 约 5 分钟（赛前 3 分钟决策 + 赛中 2 分钟观赛/跳过） |
| 单局决策点 | ban 图、阵容、战术权重、经济策略、暂停，共 5 处，密度适中 |
| 数值主线 | 属性 → 战力 → 胜率修正 → 回合判定，单链条，易调平衡 |
| 养成线 | 无（数值写死），深度由触发器个体差承担 |
| 玩家心智负担 | 选人比三个数，30 秒可组队；深度藏在触发器与配队 |
