# 十人自主行动、开局前出与 Split 枪线验收

实施开始：2026-10-07；验收：2026-10-08。工作目录保留原有混合改动，不委派、不提交、不重置个人数据库。数值审计只调用模拟模块；浏览器只使用独立章节。

## 已落实

- 每名选手有自己的动作记忆、查看角度的时间、原架点和实际可见目标。意识影响检查节奏、协同影响前出间隔和补枪目标选择；附近队友正在对枪时，优先协助自己真正看得见的目标，不读取未观察敌人的计划或实时坐标。现有卡牌、队伍、教练、地图、英雄技能和战术输入继续使用原适配接口。
- 开局先沿合法路线前出，进点时机与赶路分开。佯攻真打组在入口集结，收到实际佯攻信号后衔接；绕后路线只前出到第一个包点入口，避免把整条绕后路线的倒数第二个节点误当集结点。
- 安静时短探头并回到原架点，防守检查限于附近且保留入口视野，同点队员错开检查。有新鲜队友报点或近期交火时保留预瞄；目标、技能避让、撤退、支援和拆包仍优先。移动到具名站位先预约、到达才获得站位；三个单位的短探头也会实际返回，修复旧 `>3` 边界漏回位的问题。
- Split 中路直射 B 点问题已复现并修复。漏掉的是原参考布局 `split-v2` 的 B 高塔楼梯侧墙（结构轮廓14的西侧），新增物理阻挡，同时阻挡射击和横穿。高塔绕楼梯通往 B 二楼的路线和 B 二楼打包点的合法枪线仍存在。未使用“中路/B点区域名禁止交火”的规则。
- 身体边缘采样使用身体中心的楼层高度，且必须与身体连通，不能借邻近地台高度或把肩膀伸进另一侧墙体来制造枪线。站位静态表和枪线表使用新几何重新编译；移动、烟雾、门状态变化仍按实际物理射线检查。

Ascent 新行为为 `ascent-balance-5`，其余八图为 `地图ID-balance-3`，`autonomyModel=agents-1`。已发布的旧版本和历史回放不补算。浏览器包与 Node 使用同一份源代码，缓存版本为 `agent-autonomy-3`。本批交付后这些候选版本冻结；后续改变行为应另立版本。

## 验证

工程回归 **358项通过、0失败**，见 `2026-10-07-agent-autonomy/regression-current.txt`。包含九图 Node/浏览器同源、保存后继续的事件一致性、九图强制佯攻开局五名进攻选手五秒内出现真实移动、协同目标不越过可见性、回防/拆包目标优先、压力下保留架点、三单位短探头实际归位，以及墙/门/高差/身体边缘采样。

Split 专项检查全部中路站位到 B 包点站位，及附近实际偏移位置；新静态表和真实射线都阻挡原来的错误连接。合法高塔通路和 B 二楼到包点枪线另有正向断言。过去“模型内非法枪线为0”只能证明实现遵守模型；当墙体本身缺失时，模型会把现实中错误的枪线判为合法。本批使用原图对应的位置专项来补这个缺口，仍不等同于全部真实地图实机认证。

开发对照发现频繁防守检查角度损失了已准备的站位。相同 `compiled` 种子、四组阵容、攻防镜像的 Ascent 小样本：频繁检查版本62.61%攻方；关闭新防守动作的诊断对照49.70%；仅回退进攻接敌选择的对照61.93%；调整检查节奏、报点保持和站位预约后50.61%。这些是定位用开发样本，不能代替最终独立审计。

最终数值证据采用 `reset-held`，每图12组攻防镜像（24张完整地图），EDG/TE/BLG/DRG各三组，同阵容/同强度/同地图分/同风格。每张地图保留冻结输入、比分、逐队分层和射击检查，源码哈希与实际源文件快照位于 `2026-10-07-agent-autonomy/sources/`。汇总生成后使用 `summary-final.json`，正式发布门槛仍关闭。开发批次不能与当前候选混在一起做平衡结论。

最终完成 **216张完整地图、4453回合、262826条射击**，按该版几何规则检查非法枪线为0。九图佯攻样本的首次移动中位数1.5秒、最晚2秒（此数值审计的默认英雄配置）；浏览器快速选英雄的真实配置五秒时五人均已实际前出，施放技能仍会占用个人动作时间。

## 保留的发布边界

正式征战仍使用现有队伍层模型。新空间行为在独立观战中可验收，尚不能把功能通过等同于全部地图/阵容攻防平衡通过；真实补丁的局部高差/特殊机关、更多长期阵容与战术分层仍需验证。胜率是实际模拟结果，不做55%截断、败者改判或强制重抽。
