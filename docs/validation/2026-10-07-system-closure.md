# 当前征战系统收尾验收

日期：2026-10-07。入口仍为 `设计文档/UI原型/complete-prototype-01/`。缓存版本 `system-closure-4`。个人存档、旧业务数据库和原始内容均未被测试重置；所有数据库验收采用唯一 `val-manager-test-*` 名称。

## 实装内容

- 当前前端以 `career-store.js` 的 IndexedDB 事务记录为正式业务来源。旧 `vm-complete-ui-v3` 只读迁移，保留原始文本；旧业务 `storage.js` 数据库不改写。预览仍隔离使用自己的沙盒键。
- 赛年保存 CN/全球卡牌、卡包配置、特工池及地图目录快照；开始新赛年使用更新内容，历史赛年另保留卡面快照。已有年度赛果和奖励不重发。原始旧 UI 档没有历史卡值快照，首次迁移冻结本次未改变的制作数据，不声称可以恢复早于首次冻结时已经丢失的属性。
- 校验损坏、未知卡/比赛/赛事版本、无效属性和不安全资源路径；失败时停止提交并保留原文。并发比较修订号和完整记录指纹，恢复模式也不能绕过争用保护。
- 设置增加导出、预检导入、上一个有效记录恢复。恢复前保存被替换的完整记录。备份有可点击下载链接及复制文本备用入口。当前验收浏览器没有产生 Blob 下载事件，不能把原生文件下载当作已实测成功；复制出的完整备份及文件导入已实际验证。
- 正式比赛的相对预期表现用于阶段临时反馈：按有效地图回合数收缩，最多 ±0.75 等效实力，仅传给后续快速赛，结算阶段后清除；不再叠加永久三维。正式节点若因已提交的前置赛果不可达，新版本从仍可达的合法对局中择近；确认后的节点固定。
- 全球 62 个赛事席位都可使用五人模拟输入。TL/GX 两名缺卡以队友均值代理，十二支海外挑战者仍采用五个中性 65 代理；共 14 支队伍含代理。它们不进入 CN 抽卡池，不冒充原作者制作的真实选手卡。真实卡值及 Ranking 参考维持原样；Ranking 没有重复加成。
- 启动加载提示及保存完成反馈已补；缓存补入漏掉的成长模块。全部启动脚本与离线清单路径通过检查。桌面 360×640 页无横向溢出；未冒充真机安装、断网启动或系统强杀验收。
