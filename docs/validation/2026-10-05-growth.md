# 成长继承与海外国内赛事数值模拟验收

日期：2026-10-05。运行入口仍为 `设计文档/UI原型/complete-prototype-01/`。本批完成 N3 的当前前端实现；独立地图比赛引擎项目 E 未执行。

## 已接入的行为

新增 `游戏/progression.js`，由正式前端 `runtime-model.js` 调用。模块只消费已经产生的赛果，不选择胜者、不重放赛事来发奖励。普通章节样例仍隔离，自己的征战与实际 BO5/Ascent 验收场景使用 live 结算。

- 队伍羁绊：熟识、真实同队和本届十对共同参赛关系合成。换一人保留原四人的六对关系，新人相关关系按已有真实共同经历计算；招募本身不发收益。
- 状态：逐分胜负产生波动，向 50 回归。中场、地图结束和系列结束分别恢复；暂停仅恢复低于 50 的状态。同一窗口只结算一次，不按点击次数奖励教练。
- 熟练：逐分 `0.04×(1−L/100)`，每场系列再 `0.3×(1−L/100)`；换人按留队比例延续相对教练提供的基础值。BO5 的比赛层增量与 BO3 一样只发一次。
- 地图：显示分 `D=0.6H+0.4M`。教练积累 `H+=2×(胜负−开图预期)`，阵容磨合 `M+=学习速率×(1−M/100)`，胜/负学习速率 1.5/0.8。换人仅让 M 相对 50 的积累按留队比例保留；新赛年保留 H、M 回到 50，候补地图记录也保留。
- 熟识：开图冻结实际参赛版本、选手 ID 和声望，实际每图 U 增量 `(1+0.25×获胜)×(0.75+0.005×开图声望)`，可见值 `F=100U/(U+40)`。各版本共享选手 U；荣誉仍按实际上场版本，不复制给未上场版本。
- 赛事收益：按实际出场地图份额×赛事权重×成绩档发放额外 U。离队者保留自己参加赛事的收益，新人不追领旧赛事。资格同分加赛有实际比赛成长，但不当作冠军赛入场、不领取未参加的冠军赛收益。
- 教练：战术/临场每场缓慢向有证据的目标更新，各最多 ±1，既能升也能降；声望按阶段排名分位更新，每阶段最多 ±4，赛年结束另做一次加权年度评价，最多 ±4。年度不会重复颁发赛事熟识。
- 跨年：保留教练三维、H、熟识、图鉴与历史荣誉；重新抽包，重建队伍状态、熟练、当届关系与 M。只开包无参赛不产生熟识/荣誉。

战术目标当前仅比较地图知识、英雄适配的游戏预期与中性基线；快速比赛按签表两侧分别构造自己的地图基线。临场目标是整图实际得分相对各分预测的残差，按回合数收缩后在系列内聚合。它们是游戏评价，不是精准现实执教能力测量；具体排序的机会分析、窗口后的精细事件评分、关键表现/有效配合额外收益仍等待 E 提供真实证据。空间回合无可靠概率时不虚构临场评分。

## 前端展示与旧档兼容

`progression-views.js` 在地图、系列、阶段及年度结算提供可展开的实际净变化；教练资料展示最近评价，地图资料展示 H/M 两层。补强确认页解释保留人数和 M 的保留比例。所有收益自动产生，没有新增日常培养操作。

当前有效旧 UI 存档：保留已得熟识/荣誉，旧单层 D 初始化为 H=M=D，不让当前显示突然跳变；次年 M 才按新规则重建。已有账本防重发；部分已打旧地图标为 legacy，不倒推其战术/临场评价。不是完整旧业务版本迁移，不把旧样例荣誉改成实际赛事荣誉。

index 与 SW 已加载新模块，缓存命名包含 growth。进行中及已结算阶段使用稳定来源 ID。当前 UI 仍使用 localStorage；IndexedDB/内容冻结/异常恢复/跨标签事务统一属于 N5。

## 海外国内赛事的范围

赛年上下文标记 `simulationPolicy`；非 CN 同区且非国际比赛的结果标记 `regional-numeric`，保留系列比分、合法地图比分、胜者、名次与积分，不保存回合细报或制作空间演出。CN 与国际赛继续当前回合模型；国际赛即使双方来自同一海外赛区，也不被误判为国内比赛。

通用格式核对：[2026 官方赛事手册](https://valorantesports.com/en-US/season/115571062868511862/handbook/)、[第一赛段](https://valorantesports.com/en-US/season/115571062868511862/handbook/115571062868708473)、[第二赛段](https://valorantesports.com/en-US/season/115571062868511862/handbook/115571073559465083)及[2026 官方规则](https://cdn.sanity.io/files/dsfx7636/news_live/f600a428dbcb54cff5814750f4c4be2b699d7934.pdf)。启点三败、两组六队、第一赛段八队双败、第二赛段八队加四挑战者入围（十二队双败、全 BO3、组内第三/第四轮空、四队出线），败者决赛/总决赛 BO5 等已保留。

各地区抽签位置、冠军积分同分的地区例外仍记在 N2，尚未声称全部符合现实细则。最终同分 BO1 为明示游戏后备；海外缺少真实阵容的席位仍用显式中性先验，不凭空制作原卡三维。数值模拟只简化演出，不跳过前置签表或随意授予资格。
