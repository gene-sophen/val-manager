# 整体前端检查与修复

发布版本：`20261009-audit-7`。保留原有柔白美术、卡牌品质和比赛引擎规则。

## 修复内容

- 战队名单改为五人紧凑信息列表，显示选手、品质、原队、三维与总评；点击仍可看完整卡面。赛前折叠阵容使用同款列表。
- 开包和候选五列、图鉴四列、BP两列；缩略卡补充姓名和品质，选人按钮至少44px高。比较卡包与已揭晓补强候选补齐两侧16px留白。
- 蓝色用于推进/确认，白色用于查看/返回/辅助，淡蓝描边表示选择；统一档案页签、筛选、版本按钮、回放工具、弹窗和禁用反馈。蓝色主按钮对白字对比度4.52:1。
- 返回和查看卡面的底部按钮采用辅助层级。结束征战确认使用独立颜色；设置页不再显示会再次打开自己的设置按钮。
- 新增独立导航策略：详情回到所属列表，比赛返回征战，已完成准备不会被返回操作重新开启；同页导航不会重复入栈。详情返回恢复原选手焦点。
- 进行中的BP、选边、选特工和战术准备可从首页继续。返回主队选择后继续原开包，保留已经生成的三包和揭晓进度。
- 昵称校验留在弹窗中，支持按回车保存；弹窗中的其他通知也在弹窗内显示。CN卡池移除无实际作用的赛区筛选，品质五项一行、排序三项一行。
- 正式桌面界面居中显示游戏，隐藏原型说明工作台；隔离验收页保留工作台。首局前资料页不再把原型样例或固定±1成长当成正式规则。

## 验证

- 35个页面、320/390/430宽度和320×640大字模式，共140次布局检查：可见按钮无小于44px的点击区域，无横向溢出。检查记录见 `2026-10-09-frontend-audit/final-matrix.json`；该批检查在audit-5完成，后续文案和补强留白通过针对性检查。
- 实际逐张打开三包、选五人、确认返回、组队后搜索/排序；再次进入主队选择保留原揭晓卡和数量。
- Split关键回放、下一回合、返回首页与继续：比分保持2:0，对方暂停窗口保留。取消调整恢复原五战术顺序，设置返回仍在比赛。
- 昵称空值显示弹窗内错误，回车保存后返回资料并恢复编辑按钮焦点。图鉴筛选实际改变数量；320宽度筛选按钮44px高，品质按钮约46px宽。
- 补强十张逐张揭晓，stew替换为Erv，返回后保留待确认选择。320宽度候选按钮50×44px，边距16px，无溢出。
- 冷打开地图详情后返回地图列表。1280桌面正式布局隐藏工作台，手机首页导航完整。
- 全量404项回归通过；最后发布版本再次运行34项导航、模板、存档、图片、回合展示和PWA合同检查。

全部浏览器操作使用唯一 `val-manager-test-ui-*` 数据库；没有访问个人或默认数据库。截图见 [验收目录](2026-10-09-frontend-audit/)。本轮是浏览器手机尺寸验收，真机安装、系统字体与系统键盘仍需设备体验验证。
