# Ascent v5：B 点墙门、英雄解说与外部数值

本批完成 Ascent 独立版本的三项改造，旧 v1–v4 地图/规则入口保留。正式征战默认引擎及其余八图尚未切换。

## 1. B 点真实分隔与射击落点

- 将原图可见、此前只有视觉线条的 B 长条 U 形内墙加入碰撞。当前共 15 个明确语义的分隔/箱体/门，17 区域、54 个站位、12 交火窗口。
- 市场门的开关同时影响视线、射击、通路和回放。附近存活队员需要 1 秒操作；不能跨实体墙遥控开门，关门时不封住当前站在门内的选手。走到突然关闭的门前会停下，之后重新判断路径/操作。
- 自动策略每回合尝试一次战术关门，遇闭门时当地队员可再次打开。不是完整真人门操作 AI；门 HP 字段预留，射坏门尚未制作。
- 新增“门外通道”和“长条门侧”两个站位，避免只有门内一侧站位而无法展示门的交火意义。浏览器对照：市场门架枪，开门可见 4 个站位，闭门可见 2 个。
- 目标只露出身体边缘时，实际射击与绘制枪线均使用可见边缘落点；不会把一条穿过墙体的人物中心连线画成合法射击。身体可见比例仍参与命中率。
- 下包记录实际坐标；必须进入可下包区域。拆包/捡包需要走近实际爆能器位置，不会因为同属 B 点就隔墙远距离完成互动。

这些验证证明当前碰撞模型的自洽，不能替代全部真实墙体、材质和高度的实景审核。A 门、多层导航、射坏门、弹道穿透及其余地图待制作。

## 2. 头像与解说

- 使用已有本地英雄头像替换编号小点；蓝红边框区分双方，阵亡头像淡化并标叉，悬停可见选手/英雄/HP。
- `游戏/commentary.js` 从事件生成战术开场、接敌、击杀/多杀/残局人数、佯攻、补防、封烟、门、下包/拆包和卡特性播报。
- 解说不请求生成模型、不使用随机数，只显示当前回放时间以前的事实；镜像同名选手击杀时补上队名，复活会更新存活人数。
- 玩家可主动开启浏览器语音，开启后以 1× 播放；暂停、拖动与换局不影响赛果。声音依赖浏览器/系统声线，文字解说始终可用。本批核对开关和速度变化，未以系统实际音色/声学质量作为已验收结论。
- “本分队员”详情提供本回合初始执行三维，便于核对输入值及状态修正；卡面原三维不修改。

## 3. 外部数值连接

`引擎/external-effects.js` 将原卡、状态和教练配置绑定到新版核心，既支持 `游戏/spatial-match.js`，也支持 v5 地图的原始引擎队伍输入。

| 输入 | 实际落点 |
|---|---|
| 选手 AIM | 射击命中、爆头及动作倾向 |
| 选手 SYN | 沟通延迟、道具衔接、协作倾向及真实补枪目标的接敌响应 |
| 选手 SEN | 接敌反应、决策噪声、选位及信息反应 |
| 队伍羁绊 | 小幅调整当前协作执行；不改原卡 SYN |
| 队伍状态 | 小幅调整当前射击执行，个人局内情绪仍由事件维护 |
| 队伍熟练 | 调整战术/协作执行 |
| 地图分 | 调整当前地图意识执行 |
| 教练战术 | 准备/决策意识修正、自动指挥选择与对手倾向读取 |
| 教练临场 | 暂停负情绪恢复 |
| 教练声望 | 保留已确定的成长、熟识、初始羁绊链，不另叠一层子弹命中奖励 |
| 五攻/五防排序 | 变成真实战术意图及执行路线；合法窗口调整作用于后续回合 |
| 招牌英雄 | 已确认英雄的技能效果效率 ×1.15，结合池内/池外适配 |

输入及可见属性限制在 0–100；缺少选手三维或非法数字拒绝执行。临时属性由原卡和冻结状态重算，不因循环/回放叠加。队伍局内状态经回合命令日志传入；卡牌/特性版本及初始参数冻结，未知版本拒绝续写。

### 金卡与钻卡

`游戏/build-card-effects.cjs` 从既有金卡文档提取 60 个分配，配置 13 个方向；首杀、Rush、多杀、赛点、残局、技能衔接、补枪、连败、埋伏、防守、信息、轻装等条件产生有界的属性增益。首杀必须已获得真实目标，技能衔接需要本人和附近队友的施放证据，不在部署阶段凭空宣布成功。

当前 CN 五张钻卡均接入，每张每图一次：

| 切面 / 明星时刻 | 当前局内实现 |
|---|---|
| 23东京 ZmjjKK / 冥驹审判 | 残局意识强化，并封锁对方随机发挥和卡牌触发；不抹掉墙体或原始能力 |
| 24首尔 ZmjjKK / 降维打击 | 赛点本回合合法射击的命中两骰取优 |
| 25曼谷 CHICHOO / 一人成军 | 1vN 中持续锁定一个实际可见目标，每次击破后小幅递增枪法 |
| 25多伦多 Spring / 黑马之蹄 | 落后至少 3 分触发，全队执行增益持续至追平；本人本分阵亡不提前取消 |
| 23洛杉矶 whzy / 无情判官 | 对整体执行实力更强的对手触发，个人短期枪法强化，持续 3 回合 |

**两处动作化转换需注意：**“降维打击”从重抽整回合胜率转成命中稳定性；“一人成军”不冻结其他敌人，保留真实同时交火，只固定目标与连杀递增。保留名称、切面及原卡数值，具体转换已存入配置，创作者可据此调整。其他赛区钻卡未接入，不会伪装成某张 CN 卡生效。数字尚未完成平衡验收。

## 4. 验证与入口

- 全工程原生测试 **200 通过、0 失败**。覆盖旧版本、B 内墙、门、移动阻挡、身体边缘射击、属性边界、特性实际条件/不累加、补枪响应、五切面/每图一次、恢复、浏览器 bundle 和解说时间过滤。日志：`2026-10-06-ascent-v5/full-tests.txt`。
- 最终诊断 **12 场、246 回合、13,859 次射击**；当前模型内射线校验 **0 次被墙/闭门阻断却仍开枪**。4,969 次选择身体边缘落点、69 次门状态变化；五个 CN 明星时刻都在完整对局中触发。结果：`2026-10-06-ascent-v5/audit.json`。
- 前 10 场覆盖五切面并交换初始攻防，另 2 场“一钻四铜 vs 五金”检验强敌/追赶条件。这是物理/特性诊断，不是等强胜率评估；`releaseGate=false`。脚本连同射线反查共 50.2 秒，不能当作正式纯引擎性能指标。
- 浏览器核对头像、解说、语音开关/1×、时间轴及刷新；最终独立样板未发现浏览器错误。地图检查页验证市场门架枪位开门可见 4 个站位、关门可见 2 个。截图及源码哈希存于同名验证目录。
- 新版回放：原型 `?scene=ascent-v5`；右侧按钮“Ascent 墙门、解说与卡牌效果”。墙门对照：`map-preview-ascent/layered.html`。
