# 地图风格、揭晓动效与下包前补防

用户本轮四项要求已实施，并保留攻防审计未通过的发布限制。

## 界面

- 九张地图改为白底、浅蓝边线、柔色包点的 SVG 简图，依据本地 Riot 原图人工简绘主要布局；Haven、Lotus 保留 C 点，Sunset 保留 A 右 B 左的方向，Fracture 保留上下进攻侧。省略照片背景和小箱体。简图只用于展示，不替代引擎导航与碰撞数据。
- 地图资料、静态观赛和放大面板使用同套简图，放大面板可展开官方原图；Ascent 回放事件仍沿原始 960 坐标显示。
- BP 每行一张大海报，新增 Riot 官方图库的场景截图作为海报，替换旧 3D 总览中大片灰白块的观感；原总览与俯视图文件保留。新海报不人工放大源图，记录来源 URL 和内容哈希，离线缓存覆盖九张海报。选过/禁过的地图统一标为“已处理”，不把选图误称禁图。
- 初始包和补强包均保留逐张揭晓。铜：暖色纸屑；银：蓝灰双环；金：金色星芒；钻：浅蓝菱形光环。先显品质，再翻出真实卡牌，支持跳过及减少动态效果。动画不参与抽取或重新生成卡牌。
- 右侧新增四种品质的只读动效预览，不消耗卡包、不解锁图鉴。离线壳包含九张 SVG。

## 引擎原因与修改

原模型并非完全没有下包前转防，但存在瞬时 `newInfo` 信号、锚兵提前支援限制、缺少可靠的队友阵亡通信。新增 `引擎/defense-support.js`：

1. 持续记忆近期视觉接触、可信接触强度和己方点位减员，不读取敌方隐藏分布或真实战术。
2. 按实际队友位置分配就近支援，经过意识决定的通信反应时间，再沿真实路径移动；同区域的二楼/市场队员也可以补防，不假定“同区域=正在掩护”。
3. 另一侧至少留一人；假动静不能触发新模型的全队转防，信息过期后可取消支援。
4. 守点者在自己看到明显人数劣势时可以后撤集结；不凭隐藏敌人数后撤。下包后的回防保持独立逻辑。

另发现同节点交火每 tick 可开枪、跨节点架枪额外经过 30% 开火判定的区别，会压低守点掩护火力。新空间地图统一按实际视线选择目标、结算命中，并继续限制单人单 tick 一次开火。双方移动时间统一按真实路径长度计算，取消旧节点边长对长入口的低估；取消旧版刻意缩短回防窗口的计时设置。没有添加守方胜率补偿或五类战术的直接概率加成。

旧 `spatial.version=1` 的独立预览使用旧策略恢复输入日志，新预览为 version 2；常规征战仍使用现有队伍层模型，尚未默认启用空间引擎。

## 验证

- 149 项自动回归通过：信息隔离、阵亡前后补防、另一侧留人、取消过期呼叫、真实后撤与移动、跨区域开枪、单 tick 开火限制、确定性恢复、旧版本存档、生成浏览器包一致性、赛年晋级和 BO5 流程。
- 九张 SVG 的 XML 解析通过；原官方地图文件及内容哈希保持不变。
- 浏览器实际验证四品质与跳过按钮、初始包 1→2 张、补强包只打开一张、大海报与地图放大、官方原图入口、Ascent 事件回放和刷新。
- 200 场等强镜像测试，同卡牌/英雄/教练，五种排序轮换、双方开局换边：旧版本复测进攻 **3909/4568 = 85.57%**；本版 **2906/4286 = 67.80%**，主队胜率 48.5%，全部完成，无强行指定比分。
- 仅补防的中间诊断为 79.74%，只能用于说明阶段性变化；当前最终对照以 baseline/combined 的两份同条件审计为准。

## 仍未完成

67.8% 仍超过原发布门槛 65%，且快攻对多个防守战术的胜率仍偏高；本轮修正不能宣称最终平衡达标。下一批先校准入口守点角度、交叉火力与道具拖延、集结反清、五攻五防的独立对局矩阵，再验证不同阵容与教练调整的作用。通过后才统一正式与快速模型、推广其余八图的空间推演；九张展示简图不等于九张空间引擎已完成。
