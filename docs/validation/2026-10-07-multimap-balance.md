# 八图空间行为修复与验证（2026-10-07）

状态：八图第一轮行为修复与审阅入口完成；八图全部达到攻守45–55%的验收**未完成**。六图合并样本通过，Split/Fracture仍未通过，阵容分层也仍有偏差。正式征战仍未切换为空间共核，`releaseGate=false`。

`approvedMaps`仅管理通用新空间会话默认版本。当前前端右侧「地图 · 空间观战」是明确隔离的审阅入口，会显式选择本图最新候选，未达标图也能查看本轮修复。普通新征战清除这一审阅设置，既有回放保持已保存版本。

## 已实现的修复

- 冻结 Ascent 3/4 策略和八图旧 objective-2 日志，新策略由地图ID与明确行为版本选择。旧回放不自动采用新策略。
- 防守先分配各点主守，再分配副守与游走；三包点先照顾单人守点。强接触可从弱侧增援，仍保留锚点，不读取对手隐藏计划。
- 初始守位按真实入口路径、掩体与对方可见身体比例选取。原站位附近最多9像素的局部修正均可直线合法通行，并重新编译静态枪线。Fracture/Abyss单独配置箱侧、后角与高台守位。
- Fracture A点使用入口反架与侧翼分工，替代原点内集中布防。Split保留A点双人、B点与高塔分区，在明确接触后允许实际控制位提供入口烟。
- 确认目标后持续瞄准，避免多人前后移动不断重置开枪时钟；不同到期时间的枪击先后结算，仅真正同时的枪击批量互换击杀。
- 新图枪击与观察统一使用物理视线和实际烟雾，移除第二套隐形烟雾矩阵对开枪的干扰。
- 进点、补防与回防沿实际路线推进；跟进队员保持短距队列，不挪动观战头像。头像中心依然是真实位置，可以重叠。
- 撤入掩体比较的是敌方对自己的身体可见度，不是自己能否看见敌人；绕箱路径不能超过短撤退预算。
- 躲避瞬时范围技能先验证实际路线和引爆期限，无法赶上的长路径不再强制放弃交火；持续区域伤害仍可避开。新图躲避移动采用奔跑且事件时长与模型一致。
- 下包立即中断过时的地面巡逻和补防；回防在真实位置集结，争取两人协同。时间紧迫、已清场时直接争取拆包；保留半拆进度、伤害中断和实际拆包。
- 英雄不能用通用道具虚构缺失技能或补充耗尽的充能。控制位可为首名进点队员提供实际烟雾；经过单图验证的地图可按接触/减员报告提供防守入口烟。
- 远端范围技能仅使用队友最近三秒的实际报告，加入投射延迟，不读取当前隐藏敌人坐标。区域烟墙用连续物理烟雾带参与观察与射击，不再只是宏观区域标记。
- Fracture A点回防可由有足够时间且协同/意识适合的队员走绳区—落点侧路；其余人保持正面回防。对比测试仍需核对守点入口分工，不能把绕路本身当作平衡通过证据。
- Fracture修正出生区透过中央空洞打到有遮挡防守通道的视线，仍保留滑索路线。前压/绕后不再重复占用两个中央位置而漏掉守点。
- Summit守方不会在尚未接触时不可逆地关闭自己的高塔与中路支援线路。
- 补防/回防先处理附近可操作的门；时间判断考虑开门或破门的代价，不只采用关门状态下的长绕路。
- 优化碰撞包围盒和视线查询缓存；冻结日志检查确认旧结果未变。

## 验证口径

`游戏/audit-map-balance.cjs` 保存实际卡牌、英雄、队伍与教练输入、战术排序、换边种子、当前地图配置和源码哈希。四套CN阵容双方镜像，五种优先级轮换，每图主样本24对完整地图（48场）。结果是攻守回合占比，不是主队整图获胜率，也不是对任意阵容保证相同胜率。

开发阶段与独立验证阶段分别保存；中间未完成及旧源码结果保留为诊断历史，不能当作当前通过证据。`aggregate-map-balance.cjs` 要求每个队列完整48场及当前源码一致，逐图列出通过/未通过，不用跨图平均掩盖偏差。支持合并多个同版本独立队列，追加样本时保留前一队列，不能只挑较好的结果。共享配置文件仅比较当前图的有效配置，允许其他图独立迭代。额外输出按整对种子重采样的95%区间，避免把同一地图内连续回合视为完全独立；达标判断仍是预先规定的样本占比45–55%，不等同于证明任意对局都在该区间。
