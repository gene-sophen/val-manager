# 用户重建原型的玩法对齐验收

日期：2026-10-04。基于 `设计文档/UI原型/complete-prototype-01/` 完成，保留原视觉与战队 / 征战 / 档案导航。修改前的顶层文件保存在本目录的 `2026-10-04-ui-baseline/`。

## 完成内容

- 接入既有 94 个 CN 卡版本及固定三维、照片、队标、英雄池；五张钻卡版本独立标识。
- 主队 → 三个十张包全部可见 → 选择一个整包 → 五位不同选手 → 开始；开出的卡全部解锁图鉴，最多一钻，无替补。
- 八阶段导航、未晋级分支、两次大师赛后的单包补强、不可召回的换人确认，以及仅两个大赛段开始前的两张换图。
- BO3 的 A/B 顺位选择、双方禁选、合法选边、每图英雄、攻防五类战术排序；后续地图沿用战术。
- 自动短战报、关键分布局示意、观看暂停与战术暂停分离、共同调整窗口、常规两次及全加时一次额度、领先两分结束。
- 自动成长展示、地图积累、跨版本熟识、按当时参赛版本保存荣誉、离队选手保留既得收益、年终实际参赛人员回顾与跨年继承。
- 章节预览独立沙盒，刷新保持、可返回自己的征战；不读取或修改正式业务存档。

## 接入边界

当前交付是可连续操作的前端定稿原型。抽包使用既有 CN 卡池与抽取函数；比赛赛果、晋级资格、快速比赛数量、成长幅度及荣誉名次使用明确标注的样例。战术暂不改变样例赛果，地图 SVG 和 2D 坐标为布局演示，不是正式地图战斗推演。

正式引擎接入仍按 `docs/plans/2026-10-03-season-and-match-engine-rebuild.md` 推进：真实 2026 赛事签表、积分和资格，真实地图回合事件、战术执行、统一成长账本及业务存档适配。本轮没有验收手机真机安装、软键盘或系统安全区。
