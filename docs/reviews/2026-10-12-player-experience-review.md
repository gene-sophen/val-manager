# VAL MANAGER v0.4 玩家视角界面评审

评审日期：2026-10-12。范围：本地当前入口 `设计文档/UI原型/complete-prototype-01/index.html`。

结论：已有完整的组队、执教与生涯框架，当前最值得改善的是信息层级、决策依据和赛果反馈。玩家应能持续回答三个问题：现在发生了什么、我为什么这样选、这个选择带来了什么。

## 评审依据与边界

- 浏览器实际查看：首次首页、选主队、初始卡包与逐张揭晓、设置、赛前备战、地图禁选与选边、特工选择与自动搭配、战术排序与帮助、空间观赛与放大沙盘、比赛返回首页、战队列表、卡面弹窗与选手详情、图鉴、生涯、补强开包、失利结算预览。
- 补强比较、赛事积分、阶段结算、跨年继承、异常恢复等进一步核对当前源码。没有在本轮手动打完一个完整赛年，也没有完成真机、屏幕阅读器、弱网或色彩对比度专项测试。
- 章节预览包含旧样例和当前运行分支。样例中的固定赛果说明不作为正式游戏缺陷；正式内容判断以当前运行视图及覆盖关系为准。
- 这是设计评审与建议，不是故障复现报告。下文的 P0/P1/P2 表示体验改进顺序，不表示已确认的软件缺陷严重度。
- 保留现有玩法边界：三包选一、五人首发、最多一钻、无替补、逐张揭晓、有限执教窗口、自动成长。建议不要求新增货币、训练任务或奖励领取步骤。

## 应当保留的基础

1. 白底、柔色战术图、人物卡牌容易形成自己的风格，不必整套换成暗黑电竞界面。
2. 战队 / 征战 / 档案三个主入口已经足够，不宜继续增加底部入口。
3. 固定底部推进按钮适合手机操作，保留该结构。
4. 招牌特工标记、快速搭配、回放倍速与时间轴、放大沙盘、减弱动效、大字模式均已有基础，应改善表达与布局，避免重复建设。
5. 已有自动保存、备份恢复、清空前恢复和比赛返回保护。下一步重点是让这些保护容易被理解。

## 1. 视觉与艺术方向

### V1 · P0：统一按钮层级，而不仅是颜色

实看首页的“开始征战”“查看生涯”和底部导航都很重；地图卡、战队列表、返回与设置也呈蓝色实心块。当前 `design-system.css` 末尾统一覆盖所有按钮的背景、白字和阴影，是跨页现象的来源。

建议保留蓝色品牌，但给操作分工：

- 主操作：每个页面一个主推进动作，深蓝实心，可保留厚实底边。
- 辅助操作：浅蓝或描边，例如查看资料、备份、查看历史。
- 选择控件：用浅底、明确勾选和描边表达状态，不靠深浅蓝辨认。
- 可点内容：选手行、地图卡保留内容表面；用箭头、选中角标和局部高亮提示可交互。
- 高影响操作：结束赛年、清空存档独立分区，以文字和图标说明影响。若继续采用全蓝体系，也应降低这些入口的默认权重。

验收：新玩家无需逐个读完按钮，就能识别本页下一步；未选、已选、禁用三种状态可同时辨认。

### V2 · P1：强化“电竞俱乐部执教”的识别度

首次首页目前主要是 VM 装饰和两行说明，人物与赛事的吸引力较弱。建议用小幅五人阵容拼图、主队标识、赛事章、赛年编号构成首页视觉；夺冠时才使用更鲜明的奖杯和庆祝演出。卡面品质色、队伍色、胜负色分别承担固定职责。

建议方向是“清爽的俱乐部教练室”：人物负责情感，比分和赛事章负责竞技氛围，蓝色负责操作。普通资料页保持克制，开包、关键分、夺冠形成明确高潮。

### V3 · P1：让正文达到舒适阅读尺寸

现有多处正文、卡名、属性和标签为 10–12px。关键说明和决策信息建议 14–16px；辅助标签 12–13px；标题 20–24px；比分 32–40px。五列卡缩略图属于刻意压缩的浏览模式，可保留，同时提供“阵容比较”信息视图，不把所有属性塞进缩略图。

建议基础间距 4/8/12/16/24/32，控件圆角 12、内容面板 16、弹窗 20；点击区域至少沿用已有的 44px 基础。普通按钮减少阴影，主推进按钮保留触感。

字体可沿用本地 Noto Sans SC 配系统数字字体；若确认已有 Nunito 字体包适合发布，也可用 Noto Sans SC 配 Nunito，仅用于比分和大数字。避免为改版再增加大量字体下载。

候选色板：品牌蓝 `#187EAF`，强调深蓝 `#12658E`，正文 `#263D50`，次要文字 `#526B7D`，底色 `#F6FAFC`，边线 `#DCE8EF`。胜负及品质使用独立语义色。以上为设计候选，落地时仍需检验具体文字与背景的对比度。

### V4 · P2：桌面端发挥大屏价值

当前桌面内容限制在约 430px 宽手机容器，比较和观赛都需要纵向滚动。若桌面也是目标平台，建议桌面采用“左侧阵容 / 中间主要内容 / 右侧情报”，比赛将沙盘与战报并列；手机仍保留单列流程。若近期只做手机，此项可以后置。

## 2. 首页、导航与跳转

### N1 · P0：首页成为当前任务的明确入口

比赛返回首页后可继续比赛，但首页只展示对手、赛制和继续入口，缺少恢复位置。建议主卡片按状态变化：

- 开局：已揭晓多少张、当前选包/选人步骤。
- 备战：地图禁选已完成，接下来为图一选择特工。
- 比赛：系列赛比分、当前地图比分、当前回合、是否等待执教。
- 补强：本次可替换人数与是否已确认。
- 阶段结束：实际名次、晋级结果、下一节点。

“继续比赛”可附副标题，例如“霓虹町 · 第 13 回合 · 等待中场调整”。避免玩家为确认自己停在哪里再次进入多个页面。

### N2 · P1：阅读型详情原路返回，流程型返回写清目的地

已存在返回策略与状态保护，比赛返回首页也已实测。建议在此基础上明确区分：

- 查看选手、地图、特性属于临时阅读，关闭后回到原任务，保留筛选、滚动和选择。
- 比赛页离开显示“保存并返回征战”，不要让“退出”看起来像放弃当前赛年。
- 已提交的禁图与赛果不因返回而撤销；按钮若无法返回上一操作，应写明回到哪里。
- 从准备页查看资料后，保留“返回本场备战”的直接入口。

当前战队列表是“列表 → 卡面弹窗 → 资料页 → 查看卡面”。管理场景建议点选手直接开资料，另设卡面入口；图鉴和开包场景仍优先展示卡面。

### N3 · P1：准备流程提供连续的位置感

“地图禁选 → 特工 → 战术”在备战说明中出现，后续页面缺少统一步骤条。建议头部用小型步骤条，显示已完成、当前、待完成；后续地图显示“图二准备”，不再让玩家误以为整套准备重来。

每个步骤只允许返回规则允许修改的内容。已锁定步骤显示原因；不要为了步骤条可点击而重新开放已提交的操作。

## 3. 开局、开包与组队

### O1 · P1：首次说明交代玩家身份与核心循环

首页可改为“执教一支 CN 战队，开包组建五人阵容，决定地图、特工和战术，争取赛年冠军”。用一行图示说明“组队 → 备战 → 执教 → 生涯积累”。不必加入强制多页教程。

选主队页应直接显示“选择的是俱乐部席位，首发由你开包组建”，并用一句话交代该选择在当前规则中实际影响什么；如果不影响卡包概率，不要让玩家误以为选 EDG 更容易抽出 EDG 卡。

### O2 · P1：逐张揭晓保持节奏与连续反馈

保留逐张揭晓和现有跳过动效。把进度补成“卡包 1/3 · 本包 4/10”，增加最近揭晓卡的小缩略条，并标明是否新解锁。普通品质短动效，稀有卡完整演出；同样保留用户主动翻下一张的仪式感。

“收下”可能被理解为拥有上场资格。开局阶段可用“查看下一张”，包末再明确“本包已揭晓，稍后选择其中一包组队”。不引入一键全开来改变既定设计。

### O3 · P0：比较卡包时给出真正可比较的信息

当前三包全览主要是海报、品质、总评；玩家需要反复点卡记忆特工和特性。建议每包顶部增加：

- 品质分布与关键选手。
- 满足不重复选手、最多一钻规则的参考五人。
- 该五人的枪法/协同/意识概览、常用特工覆盖和明显缺口。
- “看详情”可固定两张候选卡作对比，不用往返打开弹窗。

如显示“最佳五人”，必须注明评价依据且只用合法阵容，不能简单取最高五个总评。也不必向玩家公开内部隐藏战力。

### O4 · P1：选五人时显示阵容完成度和不可选原因

保留五列缩略卡，额外固定已选五人条与关键缺口摘要。重复选手或第二张钻卡应在卡片附近显示原因，而不仅在点击后短暂提示。

最终确认页把“不设替补、未入选五人不可随时换回”从折叠说明前移到确认动作旁；同时写明全部揭晓卡仍计入图鉴，避免玩家担心收藏丢失。

## 4. 赛前准备与决策依据

### P1 · P0：把已有对手情报送到做决定的地方

备战页已展示对手攻防倾向与偏好地图，这是好的基础。但进入 BP、特工、战术之后需要靠记忆。

建议各页保持一个可收起的情报条：对手偏好、本队相关能力、本次可考虑的取舍。使用公开信息或本局已发生事实，不泄露隐藏 AI 决策，也不把概率优势描述成必胜。

### P2 · P0：BP 同时回答“禁哪张”和“为什么”

实看初始地图分都是 50，当前地图卡主要给出我方地图分。对新玩家而言，图片不同但决策依据几乎一样。

每张图可展示我方积累、对手公开偏好、阵容适配摘要；缺乏信息时写“暂无交手记录”。禁用、我方选择、对方选择、决胜图使用文字角标和不同图标。

已完成禁选现在藏在折叠区。建议常驻一行最近行动，如“对手禁用日落之城，现在由你选择图一”；保留完整历史折叠。选边弹窗加上“对手选定莲华古城，因此由你选择开局攻防”。

确认按钮包含地图名：“确认禁用霓虹町”。先手/后手控件改成“先禁先选 / 后禁后选”，并交代连带影响。

### P3 · P1：特工自动搭配给出简短解释

实看快速搭配把五人填满，但没有解释每个人的选择与整体组合。建议展示五人特工摘要条、已覆盖的职责/功能，以及一两条推荐理由。

例如“Smoggy 使用招牌幽影；为避免重复，stew 使用擅长的炼狱”。只在实际条件成立时展示。对于需要改人的选择，原位置直接提示重复占用者。

全特工列表加入搜索与类别过滤；手动选择后保持滚动位置。新手用“推荐 / 可用 / 不擅长”等可解释标签即可，不必塞满评分和公式。

### P4 · P0：战术页先解释行为，再要求排序

当前排序帮助已经包含克制关系，但藏在折叠内容中；战术行主要是名称、熟练和上下移。建议每行增加一句真实行为解释，并在当前对手有相关情报时给出条件提示。

保持当前五项排序机制，提供“移到首位”、可选拖动和原有上下移的键盘替代。调整时显示前后变化；首次开赛前提醒防守方案也会生效，避免只看进攻便开始。

“优势：前压争夺”可改成“面对前压争夺时较有利”；必须说明这是倾向，实际执行随局势变化。

## 5. 比赛、观赛与临场调整

### M1 · P0：让首屏优先容纳比赛本身

实看空间观赛时，标题、比分和“正在回放”说明卡挤占首屏，沙盘下半部与控制需要滚动。建议使用紧凑比分栏：系列赛比分、当前地图比分、回合和攻防同屏；压缩通用说明，使沙盘成为最大内容区。

手机默认让地图、人数变化和关键事件在同一视域。地图标注和人物应分别设置缩放策略，避免地图放大后头像和地名仍过小。已有放大沙盘，应增强它而非再增加一个同类入口。

### M2 · P0：分开三种控制，显示当前状态

当前同时存在回放暂停、自动推进、战术暂停和快进。建议分组：

- 观看控制：播放/暂停本回合、倍速、时间轴、查看本回合结果。
- 比赛推进：手动下一回合、自动推进、快速模拟至下一决策点。
- 教练决策：请求战术暂停、在开放窗口调整。

明确提示“暂停回放不会消耗战术暂停”“战术暂停将在下一可调整窗口生效”。实际生效时机应以引擎为准。

当前底部“跳过回放”很突出，首屏又可能看不到播放控制。建议观看中的主视觉围绕回放；跳过保留为次操作。希望纯战报推进的玩家可明确选择自己的观赛偏好。

### M3 · P1：战报兼顾事实、理解和调参入口

当前已有关键局势和双方战术，建议把这些记录整理为“发生了什么 / 有哪些证据 / 可考虑什么”。

例如，确有事件支持时写“近三回合有两次在 B 区先减员”，并给出相应回合入口。不要仅依据失利就断言战术错误，也不要把相关性写成确定因果。

暂停面板同屏展示当前比分、当前攻防、近期事件和原战术优先级，玩家才能做有根据的调整。保存后明确“已调整，将影响后续回合”。

### M4 · P1：保持关键空间信息稳定

队伍颜色应在换边后保持不变，另用“攻 / 守”标签；人数用文字和符号同步表达。死亡、技能、下包、拆包的标识不只依赖颜色。

放大沙盘中建议保留比分、倍速、事件时间和关闭按钮；普通模式与放大模式切换后继续同一回放位置。首回合提供一次可关闭的简短图例。

## 6. 赛后、赛事与补强

### R1 · P0：结果必须告诉玩家接下来会怎样

正式系列赛视图目前有胜负和地图比分，后接通用赛制说明与“结算本阶段其余比赛”。建议区分已确定和待结算：

- 当前签表已能确定的事实，直接说晋级、落入败者组或出局。
- 必须等待其他比赛的结果，写“本场已记录，模拟剩余对局后确定名次”。
- 阶段结算显示最终名次、本次积分增加、当前总积分、下一参赛阶段和补强是否到来。

不要根据单场胜负提前捏造最终资格。

### R2 · P1：成长从折叠数表变成可见收获

已有单图、系列和阶段成长记录，不需要增加领取步骤。建议默认展示最重要的两三项净变化：旧值 → 新值、增加或减少、对应原因；完整明细仍可展开。

跨层结算应标清“本图 / 本场 / 本阶段”，避免玩家把同一累计值重复理解为新奖励。成长可有简短动画，但不能延长每次普通结算。

### R3 · P1：赛事页优先解释我队的位置

当前正式赛事页偏重 CN 冠军赛积分和已完成对局列表。建议首屏显示我队当前名次、所在阶段/轮次、晋级路线；再以“本阶段 / 冠军赛积分”切换不同问题。

主队行保持显著，高亮晋级线和直通席位；同分规则保留详细说明。未决资格标为“待确定”，不将未来阶段过早呈现成已经出局。

### R4 · P0：补强将收益与代价并列展示

现有补强确认已包含队伍三维及磨合保留说明，建议改为明确的前后对照：留队、离队、新加入；基础能力和特工覆盖如何变化；羁绊、熟练、地图磨合如何变化。

让“保持原阵容，继续”更容易找到。换人后，给出实际数值或有依据的定性说明；“保留相对 50 的积累 X%”应换成直接的前后数值，把公式留在帮助中。

确认处明确列出哪些人将失去本轮上场资格，熟识与荣誉仍保留。不要把与候选人的比较动作误写成已经完成交易。

## 7. 战队、图鉴与生涯

### A1 · P1：五人管理优先于搜索

战队永远只有五名首发，当前搜索和排序占了较大首屏面积。建议先显示完整五人、招牌特工/职责覆盖、队伍三维及当前赛事，排序降为工具菜单；图鉴仍保留完整搜索筛选。

选手数据需说明总评的实际口径。实看卡片总评与三项能力不是简单均值，不能直接判定数值有误，但容易让玩家困惑。帮助应解释真实评分含义，而非为了视觉一致重新计算原卡数值。

### A2 · P0：特性详情必须解释作用

当前选手资料有“大场面先生”等名称，但资料模板没有相应效果正文。建议把每个特性做成可展开说明：生效条件、影响的行为或能力、适用边界。钻卡的赛事版本与明星时刻增加简短背景说明，帮助玩家理解珍藏价值。

没有引擎数据支持时，不填写虚构百分比，不把主题描述当成实际效果。

### A3 · P1：区分收藏与上场资格

图鉴底部已有规则说明，但玩家需要更早看到。卡片可标“当前首发 / 本局候选 / 已收藏”，避免把全部收藏误认为可自由换入的球员库。

收集进度从长列表底部前移，增加按选手或赛事版本查看，以及最近新解锁。保留原有四列图鉴；需要细看能力时切换到信息视图。

### A4 · P2：生涯让玩家记住自己的一年

建议年度回顾增加首发合影、最高成绩、重要系列赛、长期搭档与真实记录支持的高光时刻；荣誉以赛事视觉和参赛卡关联。所有亮点都应来自已保存事实。

下一赛年开始前，把继承内容和重建内容做成两列：教练、熟识、图鉴、既得荣誉等保留；新阵容和阵容磨合重新建立。已经确定的字段逐项列清，不用“阵容重置”一句话带过。

## 8. 文案、设置、异常状态和无障碍

### C1 · P0：统一动作语言和对象

以下是文案方向，不代表直接替换所有上下文：

| 当前表达 | 建议表达 | 目的 |
|---|---|---|
| 地图 BP | 地图禁选（首次附 BP） | 帮助非核心赛事玩家理解 |
| 先选图 / 后选图 | 先禁先选 / 后禁后选 | 交代实际顺位含义 |
| 确认禁用 | 确认禁用「地图名」 | 减少误点与记忆负担 |
| 收下，揭晓下一张 | 查看下一张 | 避免把收藏与入队混淆 |
| 优势：前压争夺 | 面对「前压争夺」时较有利 | 指明比较对象 |
| 快进到结算 | 快速模拟至下一执教窗口或本图结束 | 与实际停顿行为匹配；可用短按钮加副说明 |
| 保存并退出 | 保存并返回征战 | 明确不会结束赛年 |
| 本图自动成长 | 本图成长变化 | 描述玩家得到的信息 |
| 正式 / 快速 | 亲自执教 / 自动模拟 | 在玩家界面弱化内部处理方式 |
| 结束当前征战 | 提前结束本赛年 | 与正常离开区分，附实际后果 |

保留已确定的属性名“熟练”等，用“队伍熟练”“战术熟练”说明对象，不另造同义词。BO3 第一次出现可附“三局两胜”。

### C2 · P1：设置区分偏好、存档和危险操作

把导出/导入放在存档区；恢复操作附时间、赛年、阶段和比分摘要；提前结束与清空移到独立底部区域。已有确认和恢复能力继续保留，避免重复确认每个普通操作。

“☰”通常暗示菜单，当前直接进入设置，可使用齿轮与“设置”语义。版本号可下沉设置页，释放小屏页眉。

已有预览沙盒，但面向玩家的正式包可将开发章节放到更深入口，避免把旧样例与自己的游戏混淆。

### C3 · P1：保存、等待、失败各有可执行反馈

- 保存：真实提交完成才显示“已保存”；恢复时写明恢复到哪一场、哪一回合。
- 推演：显示正在计算还是正在回放，超过正常等待时给出后台继续/返回入口，不伪造百分比。
- 离线资源：区分“准备中”“已就绪”“准备失败”，提供重试；本轮一直看到准备中，原因未验证，不能据此断言离线功能坏了。
- 存档错误：当前已有保护原档和多种导出恢复入口，建议先给一个推荐步骤，其他高级恢复收进展开区。
- 空状态：无首发、图鉴无结果、无比赛记录应各自说明原因并提供相应下一步；无结果时允许一键清除筛选。
- 图片错误：保留选手名字、品质和可识别占位，不能让头像加载失败阻挡查看资料。

### C4 · P1：把已有无障碍基础贯穿所有页面

已有 focus-visible、表单标签、大字和减弱动效。后续验收应覆盖：Tab 顺序、Enter/Space 操作、Esc 关闭、关闭后焦点返回触发项；上下移继续可用，不能只支持拖动；选中态与胜负不只靠颜色。

数字和关键信息应在大字模式下不被省略。比赛实时播报只播重要状态，不随时间轴每一帧反复朗读。弹窗与底部操作区需检查 320/360/390/430 宽度、横屏及系统安全区。

## 推荐推进顺序与验收方式

第一轮：按钮层级；首页恢复信息；比赛首屏与控制分组；确认按钮对象；特性解释；赛果下一步和补强代价。收益主要是减少迷失、误解和重复点击。

第二轮：三包比较摘要；BP 情报与行动记录；特工推荐理由；战术含义和调整对照；成长前后值与赛事资格呈现。

第三轮：开包节奏和稀有演出；年度纪念与荣誉陈列；桌面观赛与比较布局。

建议做小规模观察性试玩，记录而非预设改善已经成立：

1. 新玩家是否能说清主队选择、三包选一、图鉴与上场资格的区别。
2. 不打开帮助，能否识别每页下一步与已选状态。
3. 选完特工和战术后，能否解释自己的取舍。
4. 能否区分暂停回放、停止自动推进和请求战术暂停。
5. 返回后能否直接恢复到原比赛和阅读位置。
6. 结算后能否说清本场结果、成长、赛事资格和下一步。
7. 确认补强前能否准确说出离队者和磨合变化。

以上只要求界面解释既有机制，不以增加操作次数作为“游戏深度”。
