## 保留与兼容

- `complete-prototype-01`名称沿用原地址，内部是当前正式版，不代表仍维护多个正式前端。
- `共享资源`保留原组件来源名称以便追溯，但仅包含实际使用的文件，不混放旧页面。
- 旧UI全部在 `归档/UI原型/`，静态发布不会上传它们。发布构建会为14个搬移资源生成旧URL别名，兼容旧缓存和已安装PWA。
- `游戏/legacy/`、`引擎/legacy/`及版本化地图行为是旧存档兼容实现，仍有运行用途，不能当作垃圾删掉。
- 过去的17个静态发布副本已移至 `.artifacts/releases/`；未发布报告及新的审计输出在 `.artifacts/validation/`，预览截图在 `.artifacts/previews/`。
- 整理清单与全部搬移文件哈希在本机 `.artifacts/organization/`；公开验收仅提交汇总，不上传临时存档和整套生成物。
- `数据源`和`素材库`保留运行数据的稳定路径。网页缓存与视频制作依赖留在本机，现有忽略规则继续生效。

原型、历史说明中的日期与数值代表当时版本；当前状态以正式入口、近期验收及已确认设计为准。
