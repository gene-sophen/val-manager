# 十名选手自主行动与交火空间优化 Implementation Plan

**Goal:** 提前离开出生区、保留战术进点时机，增加有目的的自主换位/协同，并排除身体采样穿越墙体和错误高度的枪线。

**Architecture:** 场上十名模拟选手使用已有独立效用决策与共享报告，新增版本化行动政策；不是调用十个语言模型。导航区域、具名站位、近距离角度动作和物理射击通道分开，动作沿合法路线，射击须同时满足观测与实际可射身体落点。所有旧行为/日志保持冻结。

**Tech Stack:** CommonJS、现有RoundSim/GeometryV2/Engagements、UMD前端、node:test。

用户已授权实施；保留混合工作区和个人存档，不委派、不提交无关改动。

1. 复现：记录旧版出生区离开时间、每人长时间不动、首次接触与支援/交火事件；新报告目录`docs/validation/2026-10-07-agent-autonomy/`。
2. 新增`引擎/agent-autonomy.js`：个体根据自己视野、近时队友报告、队友任务与自身三维选择架点、短探头、换位、补枪掩护；有冷却和任务记忆，避免随机抖动及全员追同一目标。
3. `引擎/map-tactics.js`、`引擎/brain.js`：开局0.3–1.5秒分角色出发；到安全集结线再等待进点。佯攻到实际位置后制造动静，真打组根据实际佯攻信号/清晰接触适度提前进点，不从出生区等待统一绝对时刻。
4. 新增`引擎/combat-space.js`：身体边缘落点必须与目标身体中心处于同一可用空间，射线高度取中心而非邻近地台；新日志记录实际射击高度/通道。静态可见表不能绕过新物理验证。
5. 新日志版本Ascent `ascent-balance-5`，其余八图 `地图ID-balance-3`；新UI独立审阅使用新版，正式征战发布门槛保持原条件。旧版本不自动重算。
6. 验证独立/协同决策、战术开局、墙/门/高度边界、旧回放和新版恢复/浏览器一致；九图开发与独立样本区分，记录行为及胜率，不强制改判结果。
7. 同源浏览器包/缓存、实际观战截图与报告；明确真实地图仍未核实的局部几何，不把模型内检查等同于实机全地图认证。

实施结果：以上功能已接入九图独立预览；Split 中路→B点另补原参考图对应楼梯侧墙，静态表/移动/动态射线共用新几何。358项回归通过。验收开始日与完成日跨夜，详见[行动与枪线验收](../validation/2026-10-07-agent-autonomy.md)及最终 `reset-held` 汇总；整体正式发布仍须分层平衡与真实机关验证。
