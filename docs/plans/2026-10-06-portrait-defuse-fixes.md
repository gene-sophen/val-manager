# 头像连续性与拆包修复 Implementation Plan

**Goal:** 修复正常回放时头像突然换位，以及攻方被清空后防守不接近爆能器/不拆包的问题。

**Architecture:** 头像展示保留真实位置，增加独立的连续布局状态和按回放时间平滑；死亡立即退出绘制，其他头像逐步回归。拆包沿用物理接近与计时，不直接发放胜利；检查回防、保枪状态、精确位置导航和拆包占用。

**Tech Stack:** CommonJS、浏览器 SVG、Node 原生测试、现有共享空间引擎。

1. 定位头像无记忆逐帧重排、拆包距离/回防路由的复现案例。
2. 增加连续运动/死亡/回放跳转与攻方团灭后真实拆包的失败测试。
3. 实现最小修复，保留旧版回放恢复边界；重建浏览器共享包并更新缓存。
4. 回归、固定整图诊断和浏览器观战，记录实际拆包动作与剩余平衡问题。

用户已授权继续修复；不重置混合工作目录，不切换正式征战默认引擎。

实现已完成：连续偏移、头像节点复用、预订不传送、固定下包位置、清场后直接接近/取消可追回的保枪、单人七秒拆包与时间不足播报。旧局按缺省行为版本恢复，新局明确 `objective-2`。专项测试和整图诊断完成，最终回归及浏览器证据见[验收](../validation/2026-10-06-portrait-defuse.md)。
