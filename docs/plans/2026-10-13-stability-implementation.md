- [x] S1：事务提交后才发布内存版本；保存/恢复/重开中止与真实多窗口冲突回归；持久化检查点及未提交进度导出。
- [x] S2：结果确认、回看、继续请求分开；倒拖、暂停、后台与减弱动画不造成静默停滞。

- [x] 体验细节：中场同组操作、实际保存比分/时间、续局比分、完成/即将开始分数、证据去重、首页阶段文字/间距/桌面布局、辅助文字对比度、诊断导出及焦点。
- [x] 独立临时库浏览器验收、旧档样本中场/加时/跨图/结算与专项测试；发布 v0.6并核对线上资源。
