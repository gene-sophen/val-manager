# 精细引擎正式征战闭环 Implementation Plan

**Goal:** 在隔离环境完成精细引擎的正式赛年/BO5/暂停/恢复/成长闭环，通过后接入新征战；用户接受Lotus的进攻倾向，不以强行压到55%作为门槛。

**Architecture:** 使用真实当前前端模块、正式赛事签表、真实开包与英雄选择、当前九图版本表。旧赛年继续保留模型。测试只使用独立对象和唯一val-manager-test-*数据库；不重置个人数据库，不修改已发布行为版本或历史赛果。

**Tech Stack:** CommonJS、当前UMD前端、node:test、隔离浏览器验收页。

1. 完整正式赛年两组种子：开包/五人、合法BP、每图英雄、精细回合、两次补强、资格/跳过、阶段和年度、次年继承。
2. BO5真实决赛签表、共享暂停/中场、加时、快进对应逻辑、JSON及事务保存恢复；结算去重/比分不重抽。
3. 检查发现的错误；保留既有旧版模型测试，独立增加新精细流程测试。
4. 全量回归和隔离浏览器关键路径通过后，填写发布ID/九图版本表、记录接受的平衡差异，启用新赛年精细模型；旧存档不自动重算或切换。
5. 用户试玩只负责体验验收：节奏、可读性、战术反馈与操作负担，不承担工程查错。

完成：三个完整赛年100图/1951回合，胜败者组BO5两路径、暂停和自然加时、浏览器事务/刷新/新年正式开包、385项回归全部通过。已发布campaign-spatial-20261008-1；旧赛年保留模型。详细证据及重演等待/PWA/海外数据边界见../validation/2026-10-08-spatial-campaign.md。
