用户授权：整体完成接入引擎之前的界面内容，再由用户提出局部改进意见。继续采用白底、厚按钮、等尺寸选手卡和战队 / 征战 / 档案三分区。

交付目录：`设计文档/UI原型/complete-prototype-01`。此前分批原型保留。新原型只保存独立的演示状态，不读取或改写游戏存档，不调用引擎。规则、数值、对手、事件、赛果和历史记录均来自可替换展示配置。

制作范围：

1. 应用外壳、三个主分区、返回/滚动/焦点恢复、预览章节面板。
2. 新征战、CN 主队选择、三包逐张开包与全部查看、选整包、选五人、确认；补强包、比较/换人、保留阵容。
3. 征战进度、赛历、阶段排名/签表样例、备战、七图 BP、选边、逐图特工选择、攻防战术排序。
4. 固定战报与地图示意观赛、播放暂停/加速/跳过、战术暂停与中场调整、单图/系列赛/阶段/赛年结果及续玩。
5. 当前战队、队伍三维、地图资料、个人/卡面/版本详情；图鉴筛选、未解锁卡状态、教练资料、历年/熟识/荣誉及设置。
6. 无征战、无记录、搜索空结果、加载、错误、离线/更新状态；手机安全区、字体放大、触控反馈、安装清单和本地离线缓存。

实现：保留已认可卡片和资料展示组件；新建 `demo-data.js`、`flow-view.js`、`archive-view.js`、`app.js`、`ui.css`、`manifest.webmanifest`、`sw.js`。统一 CSS token 和数据驱动渲染。每页首屏只有一项主要操作，复杂资料按需展开。

验收：从新征战到赛年回顾的完整演示链、补强有效性/取消、BP 与逐图选择/排序、播放恢复、导航与列表状态、所有图片、320/360/390/430px 和短屏/长文字、刷新恢复、离线重新打开、安装清单及资源缓存。用浏览器截图逐页检查，不把固定演示等同真实比赛或真机验收。
