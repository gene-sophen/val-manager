# 下一批空间平衡工作

本清单作为历史诊断参考；最新执行顺序与空间设计以[真实布局与柔色风格的 2D 地图重做](2026-10-06-2d-map-rebuild.md)为准。本轮只更新计划，不继续执行引擎修改。

本轮已经实现可观察接触/己方减员后的自动补防、另一侧留人、局部后撤、统一跨区域交火机会与路径距离计时。当前等强镜像进攻 67.8%，发布门槛未过；保留独立预览。

1. **入口与站位审计**：分别记录 A/B 进点时刻、守方首次视野/开火、补防呼叫/到场、下包时人数。检查高掩体站位是否实际覆盖入口、二楼和市场是否能形成真实交叉火力。修导航和枪线，不能给守方补概率。
2. **守点与道具决策**：强接触时考虑拖延、短退和封烟；验证道具消耗、烟雾与射击/观察一致，不允许通过全知敌方分布选最优点位。
3. **支援与反清**：区分同点补防、邻区支援和跨点转防；以到场人数与已知压力决定集结或反清，覆盖假打转点与失去视野的回撤。
4. **战术矩阵**：将五攻×五防各自锁定，而非只看排序混合的总平均；分 A/B 和经济档记录胜率、击杀、下包/拆包、超时、支援到场。定位快攻普遍过强和默认控图过弱的原因。
5. **教练影响**：用同一批种子比较赛前排序、半场和付费暂停的后续结果；检查改排序是否通过行动选择影响比赛，禁止直接加结果奖励。
6. **发布验证**：保留当前 200 场作为固定回归样本，另用未参与校准的新种子、不同实力和英雄阵容复测；确认强队趋势、攻防区间、战术差异与存档确定性后再接入征战。
7. **推广**：再实现其他地图的导航/枪线和统一正式、后台快速推演；视觉 SVG 独立维护，不作为自动生成的精确碰撞图。

不增加玩家的角色微操、支援指令或训练任务。以上均为队员自主行为；玩家仍只负责 BP、英雄阵容、战术排序和暂停调整。
