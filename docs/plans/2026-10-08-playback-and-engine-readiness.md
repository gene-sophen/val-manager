# 默认倍速与正式引擎接入核验 Implementation Plan

**Goal:** 默认观战2×，保留手动倍速选择；核对正式引擎接入条件，条件通过才启用。

**Architecture:** 只调整播放偏好，不改变模拟时钟、比分或存档中的回放事件。既有候选Ascent balance-5/八图balance-3冻结；平衡诊断使用明确的独立实验配置，不修改既有版本。正式接入必须按赛年/地图冻结模型，并验证赛果、成长、暂停、BO5、恢复和快进。

**Tech Stack:** 现有CommonJS引擎、UMD前端、node:test和独立浏览器预览。

1. 将两个种子界面默认设为2×；R.init一次性迁移旧默认1×，已迁移后的手动1×/0.5×/4×保持。空间播放和等待时间使用相同2×缺省值；说明文字同步。
2. 验证偏好迁移不改变回合、成长、阵容；验证手动1×在恢复后保留，真实浏览器新章节默认2×。
3. 对照当前正式适配器和最后独立审计，明确尚未通过的Lotus及阵容/英雄/战术/经济分层、正式年结/继承与存档全链路。不能以平均胜率或单张地图通过代替接入条件。
4. 使用独立Lotus灵活位对照确定候选修改是否有收益，保留原始比分/来源，不改判。未满足条件时不打开发布门槛；给出实际完成项和剩余项。

用户已授权默认倍速修改和条件满足后的接入，无需再次请求同意；个人/默认数据库不用于验收，不重置或替换存档。

执行结果：默认倍速与接入配置/赛年版本冻结线路已完成，363项全量回归通过，独立浏览器验证2×及原速保存。Lotus灵活位对照更差，未加入游戏；全局平衡及完整精细赛年闭环尚未通过，门槛保持关闭。详见[核验记录](../validation/2026-10-08-playback-readiness.md)。
