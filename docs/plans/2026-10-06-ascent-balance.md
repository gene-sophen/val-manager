# Ascent 防守闭环与真实位置观战 Implementation Plan

**Goal:** 修复 Ascent 的调度、守点、技能和目标行为，使同等实力、多种子换边诊断的攻守回合比例落在45–55%，缩小并重叠显示真实坐标头像。

**Architecture:** 新行为 `ascent-balance-3` 仅进入新 Ascent v5 预览，旧 objective-2 与其他地图不改结果。动作模块实现观察/技能同时处理、明确守点姿态与时效性支援、物理掩护烟与局部火区、连续目标任务；不改判赛果、不硬锁胜率。观战使用原始坐标和稳定头像节点。

**Tech Stack:** CommonJS JavaScript / Node node:test，SVG、浏览器原型，现有冻结地图与日志版本。

最终实现状态：Ascent新增区域技能修复后采用ascent-balance-4；ascent-balance-3冻结兼容。任务1–4本轮完成，96场独立主样本与48场BLG追加均落在目标范围，268项全量测试通过；详见对应validation报告。其他地图按后续逐图任务推进，总体发布门槛仍关闭。

用户已授权实施。当前混合工作区保留全部已有修改，不创建脱离当前内容的工作树、不提交。本轮不调用子代理。

## Task 1 — 测试与版本边界
- 修改 `游戏/spatial-match.js`，新增行为配置；旧日志继续原路径。
- 新建 `引擎/ascent-behavior.js`、`引擎/tests/ascent-balance.test.js`。
- 验证同时接触/闪光不偏袒数组前部、半拆恢复、不可重新拾取已下包爆能器、掩护烟真实挡视线。

## Task 2 — 行为闭环
- 修改 `引擎/combat.js`、`round.js`、`brain.js`、`movement.js`、`abilities.js`、`defense-support.js`，新增行为全部显式门控。
- 观察准备与控制效果分阶段处理；重要事件响应；按入口/覆盖/退路选位；支援与回防按距离/威胁/剩余时间执行。
- 保留真实行走/射线/计时，统一烟与局部燃烧，拆包阶段进度与受到威胁后的恢复。
- 校准先单图单种子诊断，再固定开发样本，再独立验证样本；分析中间指标与战术矩阵。

## Task 3 — 观战真实坐标
- 修改 `游戏/spectator-layout.js` 与对应测试，输出 display=position，允许叠放，死亡头像退出。
- 修改 `设计文档/UI原型/complete-prototype-01/spatial-view.js`，缩小头像、生命条、命中圈，移除位移连线；保留双色边框与稳定DOM。

## Task 4 — 验收与交付
- 新增可重复 Ascent 成对完整地图审计脚本，记录源哈希、样本/阵容/战术、回合结果及过程指标。至少开发与独立验证分开，任一侧超过55%则继续定位。
- 运行引擎/游戏必要回归，旧日志与Node/浏览器一致性；不把小样本验收当整个九图发布达标。
- 生成 `游戏/build-spatial.cjs` 浏览器包，更新 index/sw 缓存版本，浏览器检查真实坐标重叠、尺寸、播放/暂停/放大和新行为入口。
- 保存验证报告，更新当前完成状态。下一张按实际验证与用户反馈逐图推进，首轮不批量打开其他图的新行为。
