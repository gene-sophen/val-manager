# 手机征战体验优化 Implementation Plan

**Goal:** 解决手机三栏导航/组件溢出、BP信息缺失、图片慢、揭晓闪层及比赛操作不明确，并发布到现有PWA。

**Architecture:** 保持正式赛年和冻结引擎版本，仅更改展示、交互和图片派生资源。共享纯函数判断关键回合与回放状态，普通分不挂载沙盘；下一回合只推进一分，暂停/中场不自动跳过。所有浏览器验收使用唯一val-manager-test-*数据库。

**Tech Stack:** 当前HTML/CSS/UMD、Node/sharp图片编码、node:test、隔离浏览器、GitHub Pages。

1. `ui.css`与`app.js`：显式hidden规则、底栏三等分、安全区/视口高度、320–430px溢出检查；并排内容用minmax(0,1fr)，触控按钮保留44px。
2. `runtime-views.js`/BP弹层：七图两列紧凑海报、已选地图名称/顺序、选边弹窗地图海报+名称+图号+选择权；规则归入可展开说明。
3. `游戏/build-image-assets.cjs`/`image-assets.js`/卡片与FLOW资产URL：保留原图，导出WebP缩略/详情尺寸；懒加载列表，首张揭晓提前解码；缓存只取优化后的游戏资源。
4. 抽卡揭晓：背景/光晕/卡牌共用一个持续容器，显现时渐隐前景，背景到结束仍保留；跳过动效和减少动画完整显示卡牌。
5. 精简各流程重复口号/开发用语，仅保留信息、限制、操作和可展开玩法说明。
6. `游戏/round-presentation.js`/`runtime-views.js`/`spatial-view.js`/`app.js`：定义首分、换边首分、关键赛点/加时/关键残局等回放；普通分仅显示比分和关键结果。按钮为观看本分、下一回合、自动推进、战术暂停、快进到结算；回放可跳过，暂停窗口需玩家确认继续。
7. 验证同一回合不重抽/不重复成长、下一分只推进一次、暂停窗口不跳过、回放选择一致，图片质量/体积及移动布局；构建发布并保留个人存档。
