## 1. 分层契约与复用范围

| 层 | 负责 | 不负责 |
|---|---|---|
| 赛事模拟 | 分组、种子、签表、资格、积分、选正式场、前缀提交和后续重算 | 不直接掷硬币填比分、不改对手强度 |
| 系列赛/单图 | BP、BO3/BO5、选英雄、换边、暂停、单图结果 | 不根据现实排行榜保送，不生成未打地图 |
| 回合模拟 | 选手自主行动、观察、交火、技能、经济、客观事件 | 不读未来赛程、不强迫玩家微操 |
| 结算/播放 | 真实参赛名单、成长、同源短报与 2D | 不重新随机生成演出胜负，不重复发奖 |

建议接口（均为待实现契约）：赛事提供 `matchId / participants / rulesVersion / officialBestOf / playedBestOf / seed`；系列赛返回实际地图比分、回合事实、参赛名单和结束原因；结算以稳定事件 ID 入账。预演副本可产生临时成长，但不能写永久存档。

保留 `引擎/round.js`、交火/技能/观察/事件与现有生成器架构。修改时先以旧基线定位影响，不全面改写枪法、伤害、寻路和随机模型。旧成长选择入口与增益在新流程替换完成后统一退出，避免双重成长。

## 2. 逐项任务

每项开工时按“补关键反例测试 → 确认旧实现不能满足 → 最小实现 → 运行该项测试 → 更新状态”执行。下列路径按状态表区分已创建与待创建；避免测试只复述实现，优先验证可观察行为与恢复一致性。不自动提交已有工作区改动。

每个编号步骤作为单独工作项执行；失败则修复当前项，不继续堆叠后续改动。新增接口代码示例是待实现契约，不表示函数已经存在。每一批更新本文件状态和验证记录；如保存 Git 检查点，只包含本批明确归属的文件，不把已有脏工作区一并提交。
