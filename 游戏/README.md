# 游戏规则与开发入口

正式界面位于[当前前端](../设计文档/UI原型/complete-prototype-01/README.md)。本目录提供卡包、阵容、赛程、BP、成长、持久存档及空间引擎适配，不是另一套正式UI。

| 位置 | 用途 |
|---|---|
| 根目录的JS模块 | 运行规则与业务代码 |
| `content/` | 制作时冻结的规则和内容配置 |
| `tests/` | 模块回归、独立浏览器验收与测试夹具 |
| [tools/](tools/README.md) | 构建、审计、诊断与报告工具 |
| `legacy/` | 旧存档和旧规则兼容代码 |
| `out/` | 兼容开发工具的本地输出与隔离验收页，不提交 |

当前正式征战接入九图空间引擎、2026赛程、两次补强、逐分成长和跨年继承。引擎行为仍由 `引擎/` 与版本化地图配置提供；整理目录不改变数值或旧日志恢复策略。

在仓库根目录执行 `node 游戏/tools/build-spatial.cjs`重建同源浏览器包，`node 游戏/tools/build-pages.cjs`构建发布目录。其余工具见tools导航。早期独立业务开局说明已归入[历史说明](../归档/说明记录/征战工程-2026-10-05.md)。

所有浏览器测试必须使用独立的 `val-manager-test-*`数据库；不得用默认库或清空个人进度来验收。
