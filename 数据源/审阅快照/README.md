来源均为号角已渲染网页；JSON 中每队保留来源链接。页面列表为“当前选手”，不自动解释成固定首发。近三月日期边界未明示，因此开始/结束日期留空；未把网站统计窗口伪装成某个精确日期范围。

JSON 中 `sourceListedPlayers` 是网页记录，`proposedFive` 是用户已批准的游戏阵容建议；两者必须分开。`rankingStableRank=false` 表示 AT/KBG 本次排名显示横线；其他队该字段为 null，未额外转录其名次，不能据此推断它们也未排名。

复核结果：50 个唯一队伍（基础席位每赛区 12 队，另 CN 入围候选 2 队）；每个提议阵容恰好五个不同选手；九图覆盖汇总与采集汇总一致；建议阵容中缺卡两人。网站当前列表中的其他缺卡也已保留，不自动补造属性。

后续修改建议时同步更新 JSON 与审阅表；保留原始转录作为依据。本批设计批准已记录在 JSON 的 reviewDecision；正式发布仍需另建具有阵容适用范围和明确赛事统计范围的内容版本，不能把本目录直接改名冒充生产数据。
